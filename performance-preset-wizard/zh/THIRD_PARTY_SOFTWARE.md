# 第三方软件

Performance Preset Wizard **不包含任何第三方源代码、可执行二进制文件、AI 模型、Node.js、Python 或独立的外部程序**。它是一个 C++ Unreal Engine 插件（编辑器 + 运行时模块），完全依赖 Unreal Engine 标准模块和 API（Scalability、控制台变量、DataAssets、UMG、编辑器 UI）。附带的示例预设仅为普通 Unreal 数据资产。

安装或使用本插件不需要任何外部软件、账户或额外的运行时环境。

**Fab 第三方声明：** 未包含任何第三方软件。
