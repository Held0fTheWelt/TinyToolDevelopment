# Software di terze parti

Performance Preset Wizard **non include codice sorgente di terze parti, binari di esecuzione, modelli di IA, Node.js, Python o eseguibili indipendenti**. È un plugin C++ per Unreal Engine (moduli editor e runtime) che utilizza esclusivamente i moduli di Unreal Engine e le API standard (scalabilità, variabili di console, DataAsset, UMG, interfaccia dell'editor). Gli asset di esempio inclusi sono semplici asset di dati di Unreal.

Nessun software esterno, account o ambiente di esecuzione è richiesto per installare o utilizzare il plugin.

**Dichiarazione Fab di terze parti:** nessun software di terze parti incluso.
