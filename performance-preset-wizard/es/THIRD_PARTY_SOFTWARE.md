# Software de terceros

Performance Preset Wizard **no incluye código fuente de terceros, binarios de ejecución, modelos de IA, Node.js, Python ni ejecutables independientes**. Es un plugin C++ para Unreal Engine (módulos para el editor y tiempo de ejecución) que utiliza exclusivamente los módulos de Unreal Engine y las API estándar (escalabilidad, variables de consola, DataAssets, UMG, interfaz del editor). Los ejemplos de preajustes incluidos son simples assets de datos de Unreal.

No se requiere ningún software externo, cuenta ni entorno de ejecución para instalar o utilizar el plugin.

**Declaración Fab de terceros:** no se incluye software de terceros.
