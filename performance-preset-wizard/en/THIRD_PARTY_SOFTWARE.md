# Third-Party Software

Performance Preset Wizard **bundles no third-party source code, runtime binaries, AI models,
Node.js, Python, or standalone executables**. It is a C++ Unreal Engine plugin (editor + runtime
modules) that uses only Unreal Engine modules and standard Unreal APIs (scalability, console
variables, DataAssets, UMG, editor UI). The bundled sample preset assets are plain Unreal data
assets, not third-party software.

No external software, account, or runtime is required to install or use the plugin.

**Fab third-party software declaration:** no bundled third-party software.
