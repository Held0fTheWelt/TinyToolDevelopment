# サードパーティ製ソフトウェア

Performance Preset Wizard には、**サードパーティ製のソースコード、実行用バイナリ、AI モデル、Node.js、Python、独立した実行ファイルは一切含まれていません**。本プラグインは C++ で記述された Unreal Engine プラグイン（エディタ + 実行時モジュール）であり、Unreal Engine の標準モジュールおよび API（スケーラビリティ、コンソール変数、DataAsset、UMG、エディタ UI）のみを使用しています。同梱されているサンプルプリセットは単なる Unreal データアセットです。

プラグインのインストールおよび使用にあたり、外部ソフトウェア、アカウント、または追加の実行環境は不要です。

**Fab サードパーティ開示:** サードパーティ製ソフトウェアの同梱はありません。
