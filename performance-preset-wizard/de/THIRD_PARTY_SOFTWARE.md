# Software von Drittanbietern

Performance Preset Wizard **enthält keinen Quellcode von Drittanbietern, keine Ausführungsbinärdateien, KI-Modelle, Node.js, Python oder unabhängige ausführbare Dateien**. Es handelt sich um ein Unreal-Engine-C++-Plugin (Editor- und Laufzeitmodule), das ausschließlich Unreal-Engine-Module und Standard-APIs (Scalability, Console Variables, DataAssets, UMG, Editor-UI) verwendet. Die mitgelieferten Beispiel-Voreinstellungen sind einfache Unreal-Data-Assets.

Für die Installation oder Nutzung des Plugins ist keine externe Software, kein Konto und keine zusätzliche Laufzeitumgebung erforderlich.

**Fab-Drittanbieter-Erklärung:** Keine Software von Drittanbietern enthalten.
