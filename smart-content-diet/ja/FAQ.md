# よくある質問

**Smart Content Diet には AI、アカウント、または別のプラグインが必要ですか？**
いいえ。コアループ（スキャン → 確認 → 安全な修正の適用 → 再スキャン → 測定）は、AI サービス、アカウント、または他のプラグインを一切使用せずに、エディター内で完全に実行されます。**Unreal Capability Mesh (UCM)** を介したオプションのエコシステムルートは存在しますが、必須ではありません。

**実行は安全ですか？**
スキャンとプレビューは読み取り専用です。修正、削減、移動、削除の適用は**プロジェクトアセットを変更します**。バックアップ済み、ソース管理下、かつ破棄可能なワークスペースでのみ実行してください。変更を行うルートはデフォルトで承認ゲートによって制御されます。自己責任でご利用ください。

**対応しているエンジンバージョンは何ですか？**
Unreal Engine 5.4 以降です。これはエディタープラグインです。

**Quick Safe、Full、Deep スキャンの違いは何ですか？**
Quick Safe はレジストリとメタデータのみを使用します（アセットの読み込みなし、高速）。Full は、メッシュ、テクスチャ、マテリアルに関する具体的な調査結果のためにアセットを読み込みます。Deep は、マテリアルと静的メッシュの詳細なメトリクスを追加し、最も低速です。

**プリセットまたはガバナンスタブが表示されません。**
これらは高度な（エンジニア / プロデューサー）タブです。設定またはヘッダーでロールを切り替えてください。

**CI / ヘッドレス環境で実行できますか？**
はい。コマンドレットが `-QuickSafe` / `-FullScan` / `-DeepScan`、`-OptimizationQueueReport`、および `-ApplySafeQueue`（バックアップ済みプロジェクトでのみ適用）をサポートしています。

**サードパーティ製ソフトウェアをバンドルしていますか？**
いいえ。[THIRD_PARTY_SOFTWARE.md](THIRD_PARTY_SOFTWARE.md) を参照してください。

**サポートはどこで受けられますか？**
Fab の製品ページにあるサポートリンクをご利用ください。
