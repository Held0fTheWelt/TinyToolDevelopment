# Software di terze parti

LightweightDummyActorSystem **non include alcun codice sorgente di terze parti, binari di runtime, modelli di intelligenza artificiale, Node.js, Python o eseguibibili autonomi**. È un plugin Unreal Engine in C++ che utilizza i moduli di runtime e dell'editor di Unreal.

## Metodo di misurazione

È stata eseguita la ricerca in `ScenePlugins/LightweightDummyActorSystem` per `ThirdParty`, `LICENSE-` e marcatori di copyright. Le intestazioni dei file contengono i marcatori EULA Standard Fab / le righe di copyright del progetto. Non è presente alcun albero di terze parti venduto.

## Integrazioni opzionali (non incluse)

WarCollection, LightningCore, Unreal Capability Mesh, Project Intelligence Orchestrator e gli adattatori BPJ sono integrazioni target opzionali e non sono ridistribuite da questo pacchetto.

**Dichiarazione software di terze parti Fab:** nessuna.
