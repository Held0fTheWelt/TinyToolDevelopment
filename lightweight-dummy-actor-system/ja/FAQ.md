# よくある質問

## LightweightDummyActorSystem の役割は何ですか？

LightweightDummyActorSystem は、ダミーアクターワークフローのランタイム表現サービスを提供します。これには、被験者の登録、ダミーアクターの表現、昇格・降格の遷移、診断、エディタインスペクタ、および検証コマンドレットが含まれます。

## 他の Tiny Tool プラグインなしでも使用可能ですか？

はい。Runtime、Editor、DeveloperTool モジュールはコアパッケージとして実装されています。WarCollection、LightningCore、UCM、PIO、BPJ アダプターは、オプションのターゲット指定統合であり、出荷時のコア動作には必要ありません。

## 対応しているエンジンバージョンは何ですか？

パッケージ化されたリリースマトリックスは、モジュールの許可リストが該当プラットフォームを許可している場合、Win64、Linux、Mac 上の Unreal Engine 5.4 から 5.8 を対象としています。

## プロジェクトアセットを自動的に変更しますか？

いいえ。コアサービスは表現と遷移状態を管理します。プロジェクト固有の変更やアダプターの動作は、所有するプロジェクトのワークフローで確認する必要があります。

## サポートはどこで受けられますか？

Fab の製品ページにあるサポートリンクをご利用ください。
