# GameFeaturedClasses-Dokumentation

GameFeaturedClasses ist eine leichtgewichtige Runtime-Plugin-Shell für projekt-spezifische Featured-Gameplay-Klassen. Die Version `1.0.1` enthält den Descriptor, die Packaging-Metadaten, das Icon, das Changelog und einen Runtime-Modulgrenzwert (`StartupModule` / `ShutdownModule`).

Zielgruppe: Teams, die heute bereits die GFC-Paketgrenze in einem Projekt benötigen, während Featured-Klassen und das Premium-GameFeature Workbench die Zielarchitektur darstellen (in diesem Paket noch nicht verfügbar).

## Aktuelles Paket

- Das Runtime-Modul `GameFeaturedClasses` wird nach Aktivierung + Neustart geladen.
- Es werden noch keine Gameplay-Featured-Class-Assets, Game-Feature-Aktionen, Registry oder Editor-Workbench ausgeliefert.
- Für die Shell ist kein weiteres Tiny-Tool-Plugin erforderlich.

## Erste Schritte

1. Aktivieren Sie das Plugin – siehe [QUICKSTART.md](QUICKSTART.md) für ein Arbeitsbeispiel (Modul-Smoke-Check).
2. Lesen Sie [UserManual.md](UserManual.md) für den aktuellen im Vergleich zur Zielgrenze.
3. Verwenden Sie [TROUBLESHOOTING.md](TROUBLESHOOTING.md), wenn ein Workbench-Menü erwartet, aber nicht vorhanden ist.
