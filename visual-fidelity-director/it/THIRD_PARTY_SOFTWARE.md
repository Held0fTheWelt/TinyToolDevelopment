# Software di terze parti

Visual Fidelity Director non richiede software runtime di terze parti.

## Requisiti runtime

- API dell'editor Unreal Engine incluse con la versione dell'engine supportata.
- Nessun servizio IA esterno.
- Nessun runtime Python.
- Nessun runtime Node.js.
- Nessun account cloud.
- Nessun altro plugin Tiny Tool.

## Componenti di terze parti inclusi

Nessuno.

## Strumenti esterni opzionali

Nessuno è richiesto per il workflow dell'editor fornito. È possibile utilizzare i propri strumenti di screenshot, video, profiling o controllo versione attorno ai report VFD, ma VFD non dipende da essi.
