# Logiciels tiers

Visual Fidelity Director ne nécessite aucun logiciel tiers lors de l'exécution.

## Exigences d'exécution

- API d'éditeur Unreal Engine incluses avec la version prise en charge de l'engine.
- Aucun service d'IA externe.
- Aucun environnement d'exécution Python.
- Aucun environnement d'exécution Node.js.
- Aucun compte cloud.
- Aucun autre plugin Tiny Tool.

## Composants tiers intégres

Aucun.

## Outils externes optionnels

Aucun n'est requis pour le workflow d'éditeur livré. Vous pouvez utiliser vos propres outils de capture d'écran, de vidéo, de profilage ou de contrôle de version autour des rapports VFD, mais VFD ne dépend pas d'eux.
