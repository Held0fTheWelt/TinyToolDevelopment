# サードパーティ製ソフトウェア

Visual Fidelity Director は、ランタイムのサードパーティ製ソフトウェアを必要としません。

## ランタイム要件

- サポートされている Engine バージョンに含まれる Unreal Engine エディタ API。
- 外部 AI サービスなし。
- Python ランタイムなし。
- Node.js ランタイムなし。
- クラウドアカウントなし。
- 他の Tiny Tool プラグインなし。

## 同梱のサードパーティ製コンポーネント

なし。

## オプションの外部ツール

同梱されているエディタワークフローに必要なものはありません。VFD レポートに関連して独自のスクリーンショット、ビデオ、プロファイリング、またはバージョン管理ツールを使用できますが、VFD はそれらに依存しません。
