# 第三方软件

Visual Fidelity Director 在运行时不需要第三方软件。

## 运行时要求

- 支持的引擎版本随附的 Unreal Engine 编辑器 API。
- 无外部 AI 服务。
- 无 Python 运行时。
- 无 Node.js 运行时。
- 无云端帐户。
- 无其他 Tiny Tool 插件。

## 捆绑的第三方组件

无。

## 可选外部工具

交付的编辑器工作流不需要任何外部工具。您可以使用自己的截图、视频、性能分析或版本控制工具配合 VFD 报告，但 VFD 不依赖它们。
