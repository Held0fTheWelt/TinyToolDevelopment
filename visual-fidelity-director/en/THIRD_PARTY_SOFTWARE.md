# Third-Party Software

Visual Fidelity Director does not require third-party runtime software.

## Runtime Requirements

- Unreal Engine editor APIs included with the supported engine version.
- No external AI service.
- No Python runtime.
- No Node.js runtime.
- No cloud account.
- No other Tiny Tool plugin.

## Bundled Third-Party Components

None.

## Optional External Tools

None are required for the shipped editor workflow. You may use your own screenshot, video, profiling,
or version-control tools around VFD reports, but VFD does not depend on them.
