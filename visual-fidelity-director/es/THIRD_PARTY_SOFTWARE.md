# Software de terceros

Visual Fidelity Director no requiere software de tiempo de ejecución de terceros.

## Requisitos de tiempo de ejecución

- API de editor de Unreal Engine incluidas con la versión de motor compatible.
- Sin servicio de IA externo.
- Sin tiempo de ejecución de Python.
- Sin tiempo de ejecución de Node.js.
- Sin cuenta en la nube.
- Sin otro complemento de Tiny Tool.

## Componentes de terceros incluidos

Ninguno.

## Herramientas externas opcionales

Ninguna es necesaria para el flujo de trabajo del editor enviado. Puede utilizar sus propias herramientas de captura de pantalla, video, perfilado o control de versiones con los informes VFD, pero VFD no depende de ellas.
