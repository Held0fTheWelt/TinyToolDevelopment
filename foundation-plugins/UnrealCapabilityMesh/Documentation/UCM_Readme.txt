Unreal Capability Mesh

Unreal Capability Mesh is a setup-driven interoperability hub for Unreal Engine plugins. It loads project-local JSON manifests, discovers declared capabilities, validates schemas and rules, plans safe routes, invokes generic endpoints, and writes local diagnostics.

Open Tools -> Unreal Capability Mesh for reload, discovery, diagnostics, route dry runs, and the plugin-grouped Route Catalog with EXPERIMENTAL self automatic approval controls.

Start with Documentation/QUICKSTART.md, then read Documentation/TechnicalOverview.md and Documentation/CodeDocumentation.md for source-level details.
