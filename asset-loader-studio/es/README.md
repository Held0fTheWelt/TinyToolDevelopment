# Documentación de Asset Loader Studio

Esta carpeta de documentación es el punto de entrada para compradores de Asset Loader Studio 1.0.1. El plugin funciona de forma independiente a través del espacio de trabajo del editor, la biblioteca de Blueprint, el subsistema de tiempo de ejecución, los perfiles de gobernanza incluidos y los registros de auditoría locales. Los manifiestos UCM/MCP son archivos de integración opcionales basados en los mismos servicios.

Comience con la [Guía de inicio rápido](QUICKSTART.md) para obtener un primer resultado visible. Utilice el manual y las páginas temáticas cuando necesite detalles más profundos sobre tiempo de ejecución, tablas, validación, configuración, automatización o solución de problemas.
