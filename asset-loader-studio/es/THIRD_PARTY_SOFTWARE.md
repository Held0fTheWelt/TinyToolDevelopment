# Software de terceros

Asset Loader Studio no incluye bibliotecas de tiempo de ejecución de terceros en su paquete para compradores.

El plugin utiliza las API de Unreal Engine y los archivos de configuración opcionales suministrados con el plugin.
Los activos del proyecto cargados, inspeccionados, editados o exportados a través de la herramienta siguen rigiéndose por los términos de licencias y activos del proyecto propietario.
