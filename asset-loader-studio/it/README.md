# Documentazione di Asset Loader Studio

Questa cartella di documentazione rappresenta il punto di ingresso per gli acquirenti di Asset Loader Studio 1.0.1. Il plugin funziona in modo autonomo tramite l'area di lavoro dell'editor, la libreria Blueprint, il sottosistema runtime, i profili di governance forniti e i registri di audit locali. I manifesti UCM/MCP sono file di integrazione opzionali basati sui medesimi servizi.

Inizia con la [Guida rapida](QUICKSTART.md) per un primo risultato visibile. Consulta il manuale e le pagine tematiche per ulteriori dettagli su runtime, tabelle, validazione, impostazioni, automazione o risoluzione dei problemi.
