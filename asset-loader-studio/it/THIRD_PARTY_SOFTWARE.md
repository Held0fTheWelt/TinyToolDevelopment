# Software di terze parti

Asset Loader Studio non include librerie di runtime di terze parti nel pacchetto per l'acquirente.

Il plugin utilizza le API di Unreal Engine e i file di configurazione opzionali forniti con il plugin.
Gli asset del progetto caricati, ispezionati, modificati o esportati tramite lo strumento rimangono regolati dai termini relativi agli asset e alle licenze del progetto proprietario.
