# サードパーティソフトウェア

Asset Loader Studio は、購入者向けパッケージにサードパーティのランタイムライブラリを同梱していません。

本プラグインは Unreal Engine の API およびプラグインに付属するオプションのコンフィグファイルを使用します。
本ツールを通じてロード、検査、編集、またはエクスポートされるプロジェクトアセットは、所有するプロジェクトのアセットおよびライセンス利用規約によって規定されます。
