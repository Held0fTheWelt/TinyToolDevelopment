# クイックスタート

## 目標

Asset Loader Studio を開き、ランタイムの読み込みリクエストを送信し、テーブルのスナップショットを確認し、ガバナンス対象の操作をプレビューし、プレビューが許可された後にのみ適用します。

## 初回実行

1. **Asset Loader Studio** を有効にし、求められた場合は Unreal Editor を再起動します。
2. **Tools > Tiny Tools > Asset Loader Studio** を開きます。
3. 通常の初回実行には **Guided** モードを選択します。検査のみが必要な場合は **Simple** を使用します。
4. `/Game/Data/DT_Items.DT_Items` のような既知の完全なオブジェクトパス、または管理下の DataAsset パスを入力し、**Inspect** をクリックします。
5. 返されたジョブのステータス、読み込まれたパス、部分的な失敗、依存関係グラフ、および診断情報を確認します。
6. 管理下の DataAsset または DataTable からテーブルのスナップショットを取得します。
7. **Validation** を開き、ミューテーションを試みる前に、不足しているアセット、重複する行、無効な参照、または権限拒否を解決します。
8. 作成、複製、名前変更、リターゲット、修復、保存、ロールバック、または削除のいずれかのアクションに対して **Preview Operation** を使用します。
9. プレビューが許可されたプロファイルの決定、許容可能なリスクレベル、および対象が変更しようとしたアセットであることを報告している場合にのみ、**Apply Operation** を使用します。
10. 適用レポートを確認し、通常の Unreal/ソース管理ワークフローを通じてダーティなパッケージを保存します。

## Blueprint およびランタイムのエントリポイント

- `SubmitLoadRequest` はランタイムの読み込みリクエストを開始し、ジョブのステータスを返します。
- `CaptureTableSnapshot` は、検証およびグラフ処理のために構造化されたテーブルデータを読み取ります。
- `PreviewOperation` は、適用前に権限プロファイルに対して計画されたミューテーションを評価します。

UCM および MCP の統合はオプションにしてください。ワークスペースおよびランタイムサブシステムが、スタンドアロンの初回使用パスとなります。
