# Documentation Asset Loader Studio

Ce dossier de documentation constitue le point d'entrée destiné aux acheteurs pour Asset Loader Studio 1.0.1. Le plugin fonctionne de manière autonome via l'espace de travail de l'éditeur, la bibliothèque Blueprint, le sous-système runtime, les profils de gouvernance fournis et les enregistrements d'audit locaux. Les manifestes UCM/MCP sont des fichiers d'intégration optionnels s'appuyant sur ces mêmes services.

Commencez par le [Démarrage rapide](QUICKSTART.md) pour obtenir un premier résultat visible. Consultez le manuel et les pages thématiques pour plus de détails sur le runtime, les tables, la validation, les paramètres, l'automatisation ou le dépannage.
