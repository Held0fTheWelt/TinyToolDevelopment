# Logiciels tiers

Asset Loader Studio ne blesse aucune bibliothèque d'exécution tierce dans son package acheteur.

Le plugin utilise les API d'Unreal Engine et les fichiers de configuration optionnels livrés avec le plugin.
Les actifs du projet chargés, inspectés, modifiés ou exportés via l'outil restent régis par les conditions d'actifs et de licence du projet propriétaire.
