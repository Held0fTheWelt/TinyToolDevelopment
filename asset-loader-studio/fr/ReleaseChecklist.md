# Liste de contrôle de la version

- [ ] Le descripteur `VersionName` est `1.0.1` et la version numérique `Version` est `3`.
- [ ] La première entrée publiée du `CHANGELOG.md` est `1.0.1`.
- [ ] Les faits du produit et le statut SAD sont « En publication ».
- [ ] Les tests de demande de chargement runtime sont réussis.
- [ ] Les tests de roundtrip du contrat JSON sont réussis.
- [ ] Les tests de capture instantanée de table et de graphe de table sont réussis.
- [ ] Les tests de comportement d'aperçu/appliquer des autorisations sont réussis.
- [ ] Les manifestes de schéma, de capacité, de point de terminaison et de route de UCM s'analysent en JSON.
- [ ] L'espace de travail de l'éditeur s'ouvre depuis le menu Tiny Tools.
- [ ] La documentation Acheteur couvre la valeur autonome avant les workflows UCM/MCP optionnels.
- [ ] Le dépannage couvre les actifs manquants, les mauvais chemins, les échecs d'application, les échecs de sauvegarde et les refus d'autorisation.
- [ ] La galerie ProductImages est rendue à 1920x1080, le horodatage du manifeste correspond à `1.0.1`, et le texte présente un espacement clair.
- [ ] Le téléchargement final des médias Fab utilise de véritables captures de l'éditeur pour l'emplacement 01 et l'emplacement 02, ou enregistre un suivi explicite avant la publication en direct.
