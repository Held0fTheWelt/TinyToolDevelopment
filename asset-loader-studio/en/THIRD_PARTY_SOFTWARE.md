# Third Party Software

Asset Loader Studio does not bundle third-party runtime libraries in its buyer package.

The plugin uses Unreal Engine APIs and the optional configuration files shipped with the plugin.
Project assets loaded, inspected, edited, or exported through the tool remain governed by the owning
project's asset and license terms.
