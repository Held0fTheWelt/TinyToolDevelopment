# Drittanbieter-Software

Asset Loader Studio bündelt keine Laufzeitbibliotheken von Drittanbietern in seinem Käuferpaket.

Das Plugin nutzt Unreal Engine APIs und die optionalen Konfigurationsdateien, die mit dem Plugin geliefert werden.
Projekt-Assets, die über das Tool geladen, inspiziert, bearbeitet oder exportiert werden, unterliegen weiterhin den Asset- und Lizenzbestimmungen des jeweiligen Projekts.
