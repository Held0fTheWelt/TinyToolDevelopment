# Dokumentation zu Asset Loader Studio

Dieser Dokumentationsordner ist der für Käufer bestimmte Einstiegspunkt für Asset Loader Studio 1.0.1. Das Plugin funktioniert eigenständig über den Editor-Workspace, die Blueprint-Bibliothek, das Runtime-Subsystem, mitgelieferte Governance-Profile und lokale Audit-Aufzeichnungen. UCM-/MCP-Manifeste sind optionale Integrationsdateien über dieselben Dienste.

Beginnen Sie mit dem [Schnellstart](QUICKSTART.md) für ein sichtbares erstes Ergebnis. Nutzen Sie das Handbuch und die Themen-Seiten, wenn Sie tiefere Details zu Runtime, Tabellen, Validierung, Einstellungen, Automatisierung oder Fehlerbehebung benötigen.
