# Release-Checkliste

- [ ] Der Descriptor `VersionName` ist `1.0.1` und die numerische `Version` ist `3`.
- [ ] Der oberste Eintrag in `CHANGELOG.md` lautet `1.0.1`.
- [ ] Produktinformationen und SAD-Status sind „In Publishment“.
- [ ] Tests zur Laufzeit-Ladeanforderung bestehen.
- [ ] JSON-Vertrags-Roundtrip-Tests bestehen.
- [ ] Tests für Tabellen-Snapshots und Tabellen-Graphen bestehen.
- [ ] Tests zum Berechtigungs-Vorschau-/Anwendungsverhalten bestehen.
- [ ] UCM-Schema, -Fähigkeit, -Endpunkt und -Routen-Manifests werden als JSON geparst.
- [ ] Der Editor-Arbeitsbereich öffnet sich über das Tiny-Tools-Menü.
- [ ] Die Buyer-Dokumentation behandelt den eigenständigen Wert vor optionalen UCM/MCP-Workflows.
- [ ] Die Fehlerbehebung behandelt fehlende Assets, falsche Pfade, fehlgeschlagene Anwendungen, fehlgeschlagene Speicherungen und Berechtigungsablehnungen.
- [ ] Die ProductImages-Galerie wird in 1920x1080 gerendert, der Manifest-Stempel entspricht `1.0.1` und der Text hat klare Abstände.
- [ ] Der finale Fab-Medien-Upload verwendet echte Editor-Aufnahmen für Slot 01 und Slot 02 oder dokumentiert ein explizites Follow-up vor der Live-Veröffentlichung.
