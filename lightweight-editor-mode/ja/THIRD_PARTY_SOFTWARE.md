# サードパーティ製ソフトウェア

Lightweight Editor Mode **には、サードパーティ製のソースコード、ランタイムバイナリ、AI モデル、Node.js、Python、スタンドアロン実行可能ファイルは一切同梱されていません**。本プラグインは、Unreal Engine モジュールおよび標準の Unreal API（拡張性、コンソール変数、ビューポート状態）のみを使用する C++ 製の Unreal Engine エディタプラグインです。

本プラグインのインストールおよび使用に、外部ソフトウェア、アカウント、追加ランタイムは一切不要です。

**Fab サードパーティ製ソフトウェアに関する宣言:** 同梱されているサードパーティ製ソフトウェアはありません。
