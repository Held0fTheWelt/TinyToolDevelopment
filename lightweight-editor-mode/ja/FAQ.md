# FAQ（よくある質問）

この FAQ は購入者およびサポートの双方に向けて作成されています。購入前、初期設定時、および実際のプロジェクトでの復元動作確認時にユーザーが尋ねると思われる質問に回答しています。

## 概要回答

### Lightweight Editor Mode とは何ですか？

Lightweight Editor Mode は、設定可能なプロファイルを通じてエディタビューポートの描画負荷を一時的に軽減する Unreal Editor プラグインです。重いシーンでの編集作業を快適にすることを目的としています。

### これはランタイムの最適化プラグインですか？

いいえ。これはエディタのワークフローツールです。パッケージ化されたゲームを最適化するものではなく、ランタイムのプロファイリングやコンテンツ最適化に代わるものではありません。

### パッケージ化されたビルドに影響しますか？

いいえ。本プラグインはエディタ専用です。Unreal Editor で作業中のエディタセッション状態のみを変更し、パッケージ化されたビルドには一切影響を与えません。

### プロジェクトを永久に変更しますか？

いいえ。本モードは一時的なオーバーレイとして設計されています。変更した値をバックアップし、無効化時にそれらを復元します。プロファイル設定はエディタのユーザー設定として保存されますが、通常の有効化/無効化ワークフローによってマップ、アセット、プロジェクトのレンダラー設定が書き換えられることはありません。

### どのようなユーザー向けですか？

広大なワールド、高密度な環境マップ、Lumen を多用したシーン、フォグの重いレベル、大量のフォリッジ配置、あるいは日常作業でエディタビューポートが重くなるプロジェクトを扱う Unreal ユーザー向けです。

## 機能と動作

### 有効化時にプラグインは何を変更できますか？

選択されたプロファイルに応じて、以下を実行できます。

- エディタビューポートのスクリーンパーセンテージの引き下げ。
- 全体的な拡張性品質の引き下げ。
- Lumen ディフューズ間接照明の無効化。
- Lumen リフレクションの無効化。
- バーチャルシャドウマップの無効化。
- ボリュメトリックフォグおよび通常のフォグの無効化。
- エディタビューポートの Unlit モードへの強制。
- エディタビューポートでのリアルタイム描画の無効化。

### 有効化中にビューポートの見た目が悪くなるのはなぜですか？

それは意図された仕様です。本プラグインはビジュアルの忠実度と引き換えにエディタの応答性を向上させます。レイアウト、構造、配置、Blueprint ロジックの編集時に使用してください。最終的なライティング、マテリアル、スクリーンショット、シネマティクス、視覚的承認の際には無効化してください。

### ビューポートが Unlit になるのはなぜですか？

ライティングはエディタビューポート描画で最も負荷が高い要素の 1 つであるため、一部のプロファイルでは Unlit を強制します。ライティングのコンテキストが必要な場合は、任意のプロファイルを編集して bForceUnlitViewports をオフにできます。

### リアルタイム描画がオフになるのはなぜですか？

一部のプロファイルでは、ビューポートが継続的に再描画されるのを防ぐためにビューポートのリアルタイム描画を無効化します。これにより、重いシーン、ノート PC、熱の放熱に制約のあるマシンでの作業がスムーズになります。この挙動はプロファイルごとに無効化できます。

### Nanite は無効化されますか？

いいえ。プラグインは Nanite を直接無効化しません。エディタビューポートのスクリーンパーセンテージ、拡張性、Lumen、バーチャルシャドウ、フォグ、表示モード、リアルタイム挙動に焦点を当てています。

### Unreal の拡張性設定を置き換えるものですか？

いいえ。より広範なエディタワークフローの一部として拡張性を使用します。Unreal の拡張性だけではエディタビューポートのあらゆる負荷をカバーできないため、プラグインはエディタビューポート独自のスクリーンパーセンテージ、選択されたレンダラー CVar、表示モード、リアルタイム動作も制御します。

## プロファイル

### どのようなプロファイルが含まれていますか？

編集可能な 4 つのプロファイルが含まれています。

- Mild
- Balanced
- Aggressive
- Extreme

Balanced が推奨されるスタート地点です。

### プロファイルをカスタマイズできますか？

はい。Project Settings > Plugins > Lightweight Editor Mode を開いてください。各プロファイルは独自の品質、スクリーンパーセンテージ、機能トグル、ビューポート挙動を持っています。

### モードが有効なままプロファイルを変更できますか？

はい。プラグインはアクティブな設定を即座に更新し、モードを最初に有効化した時点の元のバックアップを維持します。無効化すると、中間プロファイルではなく有効化前の状態に復元されます。

### どのプロファイルを使用すべきですか？

ビジュアルコンテキストが必要な場合は Mild を使用します。一般的な編集には Balanced を使用します。重いレイアウト、フォリッジ、ワールド編集には Aggressive を使用します。最大級の応答性が必要で画質を気にしない場合は Extreme を使用します。

## 復元と安全性

### モードを無効化したとき、何が復元されますか？

同一エディタセッション内では、以下が復元されます。

- バックアップされた拡張性品質レベル。
- バックアップされた CVar の値。
- プラグインによって変更されたビューポート表示モード。
- プラグインによって変更されたビューポートのリアルタイム状態。

### モードが有効なままエディタを閉じるとどうなりますか？

通常のモジュール終了処理により、モードの無効化が試みられます。エディタがクラッシュしたり予期せず終了したりした場合、メモリ内のバックアップは失われます。プラグインは再起動後に Unlit から抜け出せなくなるのを防ぐためにフォールバック表示モードを保存しますが、予期せぬ終了の後に単一セッション限定のすべての値を再構築することはできません。

### 再起動後もビューポートが Unlit のままの場合はどうすればよいですか？

Lightweight Editor Mode ウィンドウを開き、Disable Lightweight Mode をクリックします。セッションバックアップが利用できない場合、プラグインは保存されたフォールバック表示モードを使用し、Unlit ビューポートを適切な非 Unlit モードに戻します。必要に応じて、ビューポートメニューから手動で Lit に戻すこともできます。

### 他のプラグインが同じ CVar をオーバーライドすることはありますか？

はい。Unreal の CVar は、プロジェクト設定、コマンドライン、デバイスプロファイル、拡張性、他のプラグイン、およびランタイムエディタコードによって変更される可能性があります。Lightweight Editor Mode はプラグイン優先度タグ付きの CVar 書き込みを行い、自身のバックアップを復元しますが、後から他のシステムが行った書き込みが優先される場合があります。

### 存在しない CVar がエラー扱いにならないのはなぜですか？

レンダラー機能は、エンジンバージョン、プロジェクト設定、プラットフォーム、およびカスタムエンジンブランチによって異なります。CVar が存在しない場合、プラグインはモード全体を失敗させる代わりに、その CVar をスキップして状況をログに記録します。

## 互換性

### サポートされている Unreal Engine のバージョンは？

本実装は Unreal Engine 5.4 スタイルのエディタ API およびレンダラー CVar を対象としています。サポート対象として記載する予定のすべてのエンジンバージョン、特にレンダラー CVar が変更される可能性のある新しいバージョンで検証を行ってください。

### カスタムエンジンブランチで動作しますか？

必要なエディタ API および CVar が存在する限り動作します。カスタムブランチでレンダラー CVar のリネームや削除が行われている場合、それらの特定のトグルはスキップされる可能性があります。詳細は Output Log を確認してください。

### Windows、Linux、Mac で動作しますか？

プラグインはエディタ専用の C++ ソースコードで構成されており、プラットフォーム固有のランタイムコードを避けています。ただし、公式サポートを表明する前に、各ターゲットエディタプラットフォームでビルドおよびテストを行う必要があります。

### コマンドレットで動作しますか？

コマンドレット向けの特別なワークフローは提供されていません。主な挙動はインタラクティブなエディタビューポートクライアント、Slate UI、およびエディタセッション状態に依存しています。

## ワークフロー

### どのように開きますか？

Unreal Editor 内の Tools > Performance > Lightweight Editor Mode を使用します。

### 自動的に有効化するにはどうすればよいですか？

プラグインウィンドウの Enable on Editor startup にチェックを入れます。プラグインはエディタビューポートが生成されるまで待機し、現在のプロファイルを適用します。

### 起動時の自動有効化が適用まで待機するのはなぜですか？

モジュールの初期起動時には、Unreal がエディタビューポートクライアントをまだ生成していない可能性があるためです。プラグインは短いタイマーを使用し、エディタビューポートが利用可能になってからモードを有効化することで、ビューポート状態のキャプチャと変更を確実に行います。

### 終日有効にしたままにするべきですか？

可能ですが、操作の快適性のために有効化し、ビジュアルに関する決定を行う前に無効化するのが最高の運用習慣です。モードがアクティブな間に最終的なライティング、シャドウ、フォグ、マテリアル、またはスクリーンショットを評価しないでください。

### シェーダーコンパイルやソースコントロールがボトルネックの場合に効果はありますか？

いいえ。本プラグインはエディタビューポートの描画負荷のみを対象としています。シェーダーコンパイル、アセットロード、ソースコントロールの遅延、低速なディスク、ウイルス対策スキャン、高負荷なカスタムエディタツールなどの問題を解決することはありません。

## サポート

### サポート依頼時には何を含めるべきですか？

以下を含めてください。

- Unreal Engine のバージョン。
- OS。
- 標準エンジンかカスタムエンジンか。
- 選択されたプロファイル。
- 問題が有効化、プロファイル切り替え、無効化、起動時、再起動後のいずれで発生したか。
- "[Lightweight]" を含む Output Log の行。
- レンダリング CVar を変更する他のプラグインやスクリプト。

### プラグインが何を実行したか確認するには？

Unreal の Output Log を開き、以下を検索してください。

- [Lightweight]
- Backup CVar
- Restore CVar
- ApplyActiveSettings
- ApplyViewportSettings
- Lightweight mode ENABLED
- Lightweight mode DISABLED

### 最も重要な使用ルールは何ですか？

編集スピードのために Lightweight Editor Mode を使用し、視覚的な正確さのために無効化してください。
