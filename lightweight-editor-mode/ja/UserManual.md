# ユーザーマニュアル

本マニュアルでは、Unreal Engine エディタでの日常的な作業における Lightweight Editor Mode の使用方法について説明します。

## 目的

大規模な Unreal Engine シーンでは、最終的なゲームランタイムのパフォーマンスが十分であっても、エディタビューポートの描画負荷が高くなることがあります。高解像度のビューポート、Lumen、バーチャルシャドウ、ボリュメトリックフォグ、リアルタイムビューポートのアップデート、高い拡張性レベルなどは、編集中のフレームタイムを消費する原因となります。

Lightweight Editor Mode は、一時的で復元可能な編集プロファイルを素早くオン/オフできる機能を提供します。レイアウト、ブロックアウト、Blueprint の作業、フォリッジの配置、アセット配置、プロジェクトのクリーンアップなどにおいて、操作の応答性を高めたい場合に非常に役立ちます。

## ウィンドウを開く

1. Unreal Editor を開きます。
2. Lightweight Editor Mode プラグインが有効になっていることを確認します。
3. Tools > Performance > Lightweight Editor Mode を選択します。
4. プラグインのドッキング可能なエディタタブが開きます。

タブには、プロファイルのドロップダウン、切り替えボタン、オプションの起動時有効化チェックボックスが含まれています。

## プロファイルの選択

プロファイルは、エディタの描画負荷をどの程度アグレッシブに軽減するかを制御します。

### Mild

Mild は、わずかな軽量化のみを必要とするプロジェクト向けです。ビューポートの挙動を通常に近い状態に保ち、ビジュアルコンテキストを確認しながら作業したい場合に適した選択肢です。

典型的な挙動:

- 高めのスクリーンパーセンテージ（Screen Percentage）。
- アグレッシブなプロファイルよりも高い拡張性設定。
- デフォルトでは Unlit を強制しない。
- デフォルトではビューポートのリアルタイム描画を無効化しない。

### Balanced

Balanced は推奨されるデフォルト設定です。高負荷なライティングとビューポートのコストを削減しつつ、一般的な編集作業において実用的な状態を維持します。

典型的な挙動:

- 中程度のスクリーンパーセンテージ。
- 低めの全体的な拡張性。
- 高負荷なレンダリング機能を無効化。
- デフォルトで Unlit を強制し、リアルタイム描画を無効化。

### Aggressive

Aggressive は、画質よりもビューポートの応答性が重要な重いシーン向けです。

典型的な挙動:

- 低めのスクリーンパーセンテージ。
- 低（Low）レベルの拡張性。
- 高負荷なライティング、シャドウ、フォグの無効化。
- ビューポートを強制的に Unlit に設定。
- ビューポートのリアルタイム更新を無効化。

### Extreme

Extreme は、過負荷なプロジェクト、ノート PC での編集、広大なワールド、緊急で応答性を確保したい場合に使用します。シーンの構造と操作速度だけが必要な場合に適しています。

典型的な挙動:

- 非常によ低レベルのスクリーンパーセンテージ。
- 最低レベルの拡張性。
- 高負荷なレンダリング機能をすべて無効化。
- Unlit ビューポートおよび非リアルタイム編集。

## モードの有効化

1. プロファイルを選択します。
2. Enable Lightweight Mode をクリックします。
3. プラグインがアクティブなプロファイルを適用します。
4. ビューポートが即座に更新されます。

有効化時、プラグインは復元に必要な元のエディタ状態をバックアップします。

- 拡張性（Scalability）の品質レベル。
- 変更されたコンソール変数の値。
- Unlit が強制された場合のビューポート表示モード。
- リアルタイムが無効化された場合の一時的なリアルタイムオーバーライド。

## 有効化中のプロファイル変更

モードが有効になっている間に別のプロファイルを選択することもできます。プラグインはアクティブな設定を更新し、モードを最初に有効化した時点の元のバックアップを保持します。これにより、Disable Lightweight Mode を実行すると、中間で選択したプロファイルではなく、モード有効化前の元の状態に復元されます。

## モードの無効化

Disable Lightweight Mode をクリックすると、エディタの状態が復元されます。

プラグインは以下を復元します。

- バックアップされた拡張性レベル。
- プラグインによるコンソール変数のオーバーライド。モードがアクティブな間に他のシステムが同じ値を変更した場合、その新しい値が優先して保持されます。
- バックアップされたビューポート表示モード。
- 一時的なビューポートリアルタイムオーバーライド。

モードが無効化される前にエディタが再起動された場合、セッションごとのバックアップは存在しなくなります。その場合、プラグインは設定に保存されたフォールバック表示モードを使用し、控えめなビューポート復元のみを行います。この古い状態が検出されると、ボタンの表示が Restore Lightweight State に変わります。

## 起動時の有効化 (Enable on Editor startup)

Enable on Editor startup チェックボックスはユーザー設定を保存します。有効にすると、プラグインはエディタビューポートが作成されるのを待ってから、Lightweight Editor Mode を自動的に有効化します。

この遅延起動動作は意図的なものです。初期のモジュール起動時には、Unreal がエディタビューポートクライアントをまだ作成していない可能性があるため、即座のビューポート変更が適用されない場合があります。プラグインは短いタイマーを使用し、エディタの準備が整ってからモードを有効化します。

モードが無効化されないまま前のエディタセッションが終了し、その後の起動時に自動有効化が実行された場合、プラグインはまず控えめなビューポート復元を行い、その後に選択されたプロファイルを再度適用します。

## 推奨ワークフロー

### レベルのブロックアウト

Balanced または Aggressive を使用します。空間のレイアウト調整、ナビゲーションの確認、大量のアクターの移動時に、最終的なライティングは通常必要ありません。

### フォリッジやワールドの編集

Aggressive を使用します。大量のフォリッジを含むシーンは、Lit 表示かつシャドウやリアルタイム更新が有効な場合、非常に高負荷になります。

### Blueprint やゲームプレイのイテレーション

Mild または Balanced を使用します。エディタの操作性を快適にしつつ、十分なビジュアルコンテキストを維持します。

### ライティングの確認

Lightweight Editor Mode を無効にします。プラグインはライティング機能を意図的に非表示または削減しているため、最終的な視覚確認には適していません。

### シネマティクスやスクリーンショットの撮影

Lightweight Editor Mode を無効にし、プロダクション用の拡張性を復元した上で、意図したビューポートモードで確認・撮影を行います。

## Project Settings

Project Settings > Plugins > Lightweight Editor Mode を開くと、プロファイルやアクティブな値を編集できます。

プロファイル構造体は Mild、Balanced、Aggressive、Extreme の正解となるデータです。アクティブ値は、モード有効化時にランタイムヘルパーが適用するデータです。UI はモードを適用する前に、選択されたプロファイルをアクティブ値にコピーします。

## ビジュアル上の変化について

プロファイルに応じて、ビューポートは以下のように変化します。

- 解像度が低下する。
- ライティングなし（Unlit）になる。
- 詳細度が低下する。
- シャドウが減少する。
- フォグが消える。
- 手動で更新するか操作するまでリアルタイム描画されない。

これらはすべて意図された動作です。目的は最終的な描画品質ではなく、操作の快適性と速度の確保です。

## プラグインが行わないこと

- パッケージ化されたゲームランタイムの設定を変更することはありません。
- プロジェクトのレンダラー設定を永久に変更することはありません。
- マップアセットを永久に書き換えることはありません。
- Unreal の拡張性、LOD、HLOD、Nanite、コンテンツ最適化の作業を置き換えるものではありません。
- すべてのエンジンバージョンやカスタムレンダラーフォークで同一の結果を保証するものではありません。

## 実践的な習慣

Lightweight Editor Mode は「作業用モード」として使用してください。最終確認、レンダリングの不具合報告、マーケットプレイスやプロダクション用のスクリーンショット撮影の前には、必ず本モードを無効化してください。
