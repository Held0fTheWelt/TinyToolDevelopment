# 第三方软件

Lightweight Editor Mode **未包含任何第三方源代码、运行时二进制文件、AI 模型、Node.js、Python 或独立可执行文件**。它是一个 C++ Unreal Engine 编辑器插件，仅使用 Unreal Engine 模块和标准 Unreal API（可伸缩性、控制台变量、视口状态）。

安装或使用该插件不需要任何外部软件、账号或运行时。

**Fab 第三方软件声明：** 未包含第三方软件。
