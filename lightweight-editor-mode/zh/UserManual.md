# 用户手册

本手册解释如何在日常 Unreal Engine 编辑器工作中使用 Lightweight Editor Mode。

## 目的

大型 Unreal Engine 场景即使在最终游戏运行时性能良好，也可能导致编辑器视口开销巨大。高视口分辨率、Lumen、虚拟阴影、体积雾、实时视口刷帧和高可伸缩性级别都会在编辑过程中消耗宝贵的帧时间。

Lightweight Editor Mode 为您提供了一个快速开关，用于开启临时且可逆的编辑配置文件。当您需要在布局、摆放、Blueprint 工作、植被刷拾、资产放置或项目清理时获得快速响应，该插件非常有效。

## 打开窗口

1. 打开 Unreal Editor。
2. 确保 Lightweight Editor Mode 插件已启用。
3. 使用 Tools > Performance > Lightweight Editor Mode。
4. 插件将打开一个可停靠的编辑器选项卡。

选项卡包含配置文件下拉菜单、切换按钮和可选的启动复选框。

## 选择配置文件

配置文件控制编辑器降低渲染开销的激进程度。

### Mild

Mild 适用于只需要小幅提升性能的项目。它使视口行为保持接近正常状态，是仍需要视觉上下文时的理想首选。

典型行为：

- 较高的屏幕百分比（Screen Percentage）。
- 比激进配置文件更高的可伸缩性。
- 默认不强制 Unlit。
- 默认不禁用视口实时渲染。

### Balanced

Balanced 是推荐的默认设置。它降低了高开销的光照和视口开销，同时保持通用编辑的实用性。

典型行为：

- 中等屏幕百分比。
- 较低的整体可伸缩性。
- 禁用昂贵的渲染功能。
- 默认强制 Unlit 并禁用实时渲染。

### Aggressive

Aggressive 适用于重型场景，其中视口的响应速度比视觉精细度更重要。

典型行为：

- 较低的屏幕百分比。
- 低可伸缩性。
- 禁用高开销的光照、阴影和雾。
- 视口强制进入 Unlit 模式。
- 禁用视口实时刷帧。

### Extreme

Extreme 适用于超载项目、笔记本电脑编辑、大型世界或紧急响应需求。当您只需要场景结构和交互速度时使用它。

典型行为：

- 极低的屏幕百分比。
- 最低的可伸缩性。
- 禁用昂贵的渲染功能。
- Unlit 视口和非实时编辑。

## 启用模式

1. 选择一个配置文件。
2. 点击 Enable Lightweight Mode。
3. 插件应用活动配置文件。
4. 视口立即更新。

启用后，插件会备份恢复所需的原始编辑器状态：

- 可伸缩性质量级别。
- 修改后的控制台变量值。
- 视口视图模式（当强制 Unlit 时）。
- 临时视口实时重写（当禁用实时渲染时）。

## 在启用状态下更改配置文件

您可以在模式已启用的情况下选择另一个配置文件。插件会刷新活动设置，同时保留开启模式前的原始备份。这意味着点击 Disable Lightweight Mode 仍会恢复到开启模式前的状态，而不是中间的配置文件。

## 禁用模式

点击 Disable Lightweight Mode 以恢复编辑器状态。

插件恢复以下内容：

- 备份的可伸缩性级别。
- 插件的控制台变量重写。如果其他系统在模式激活期间更改了相同的值，则保留更新的值。
- 备份的视口视图模式。
- 临时视口实时重写。

如果编辑器在模式禁用前重启，则单次会话的备份不再存在。在这种情况下，插件使用设置中存储的备用视图模式，仅执行保守的视口恢复。当检测到这种旧状态时，切换按钮将显示 Restore Lightweight State。

## 启动时启用 (Enable on Editor startup)

Enable on Editor startup 复选框用于存储用户设置。启用后，插件会等待编辑器视口存在，然后自动启用 Lightweight Editor Mode。

这种延迟启动行为是故意设计的。在早期模块启动期间，Unreal 可能尚未创建编辑器视口客户端，因此可能会漏掉立即做出的视口更改。插件使用一个短定时器，并在编辑器就绪后启用该模式。

如果启动启用在之前的编辑器会话未禁用模式即结束之后运行，插件会先执行保守的视口恢复，然后再次启用所选的配置文件。

## 推荐工作流

### 关卡 Blocking

使用 Balanced 或 Aggressive。在构建空间、检查导航或移动大组 Actor 时，通常不需要最终的光照。

### 植被或世界编辑

使用 Aggressive。在带阴影和实时更新的 Lit 视图中，大型植被场景可能会非常昂贵。

### Blueprint 或游戏玩法迭代

使用 Mild 或 Balanced。在使编辑器响应更舒适的同时，保持足够的视觉上下文。

### 光照检查

禁用 Lightweight Editor Mode。插件故意隐藏或降低了光照功能，因此不适用于最终的视觉审核。

### 影视或截屏捕获

禁用 Lightweight Editor Mode，恢复生产可伸缩性，并在预期的视口模式下检查画面。

## 项目设置 (Project Settings)

打开 Project Settings > Plugins > Lightweight Editor Mode 以编辑配置文件和活动值。

配置文件结构体是 Mild、Balanced、Aggressive 和 Extreme 的数据源。活动值是运行时助手在启用模式时应用的内容。UI 在应用模式之前会将所选配置文件复制到活动值中。

## 视觉上的预期变化

根据配置文件的不同，视口可能会变成：

- 更低的分辨率。
- Unlit（无光照）。
- 减少细节。
- 减少阴影。
- 无雾效果。
- 非实时，直到手动刷新或产生交互。

这是符合预期的。目标是交互速度，而不是最终的渲染质量。

## 插件不会做的事情

- 它不会更改打包游戏的运行时设置。
- 它不会永久编辑项目渲染器设置。
- 它不会永久重写关卡地图资产。
- 它不会替代 Unreal 可伸缩性、LOD、HLOD、Nanite 或内容优化工作。
- 它不能保证在所有引擎版本和自定义渲染器分支上产生完全相同的效果。

## 实用习惯

将 Lightweight Editor Mode 作为一种工作编辑模式使用。在最终审核、报告渲染 Bug 以及捕获 Marketplace 或生产截图之前，请将其禁用。
