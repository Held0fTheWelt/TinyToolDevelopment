# Software de terceros

Internal Index Service incluye el siguiente código fuente de terceros. Marque el envío del plugin como contenedor de software de terceros e incluya esta entrada en el formulario de declaración de software de terceros de Epic.

| Software | Versión | Licencia | Fuente | Ruta en el plugin | Uso |
| --- | --- | --- | --- | --- | --- |
| hnswlib | 0.9.0 | Apache License 2.0 | https://github.com/nmslib/hnswlib | `Source/ThirdParty/hnswlib` | Backend de índice vectorial de búsqueda aproximada de vecinos más cercanos local en C++ solo de encabezados (header-only). |

El plugin empaquetado incluye los archivos originales `LICENSE` y `NOTICE.md` en `Source/ThirdParty/hnswlib`.
