# トラブルシューティング

## UE 5.6 でエンジンヘッダーエラーによりビルドが失敗する

IIS モジュールが C++20 でコンパイルされていることを確認してください。UE 5.6 エンジンヘッダーは C++20 構文を使用します。IIS の `.Build.cs` ファイルには以下を含める必要があります：

```csharp
CppStandard = CppStandardVersion.Cpp20;
```

## 検索結果が返されない

以下を確認してください：

- 準備されたチャンクがインポートされているか
- カタログが再構築されているか
- クエリテキストが空でないか
- ライフサイクル状態がアクティブであるか
- インデックスルートが期待されるプロジェクトフォルダを指しているか

## ベクトル検索結果が返されない

以下を確認してください：

- エンベディングジョブが構築されているか
- エンベディングジョブが正常に実行されたか
- LLM Store ルート/エグゼキュータが登録されているか
- ベクトルバックエンドの設定が永続化されたアーティファクトと一致しているか

## インポートが失敗する

準備されたチャンク JSONL が存在し、読み取り可能であることを確認します。バリデーションの警告や拒否されたレコードについて、IIS saved ルート下のインポートレポートを確認してください。

## HNSW インデックスがロードできない、またはバックエンド警告が発生する

HNSW バックエンドがロードできない場合、またはベクトルストレージ設定の変更後にバックエンド警告が表示される場合は、一時的に `jsonl_bruteforce` に切り替えて、ベクトルデータの問題とバックエンド固有のインデックス作成の問題を切り分けてください。**Rebuild On Vector Format Mismatch** を有効にしておくと、不互換な永続化 HNSW パーティションが誤ったバイトレイアウトでロードされる代わりに、ソースベクトルから再構築されます。

パッケージに `Source/ThirdParty/hnswlib` が存在することを確認し、**Vector Storage Format** を変更した後はベクトルアーティファクトを再構築してください。

## ランタイムチューニングまたはインデックスアクション動詞が Disabled を返す

プロジェクト設定の **Enable Runtime Control Mutations** を確認してください。これがオフの場合、`iis.control.state` などの読み取り動詞は機能しますが、tune、act、persist、および reset 動詞は意図的に無効な応答を返します。

変更を伴う制御動詞を使用する場合は設定を再度有効にするか、読み取り専用の状態および診断コマンドを継続して使用してください。

## MCP クライアントにエージェントツールが表示されない

以下を確認してください：

- Unified MCP Server が有効で実行中であるか
- Unreal Capability Mesh が有効であるか
- プロジェクト設定に IIS エージェントルートマニフェスト（`iis.agent.*.v1`）が含まれているか
- `mesh_list_routes` または `mesh_reload_setup` を呼び出し、MCP クライアントを更新します
- IIS がエージェントツールコントラクトを書き込めるか
- MCP クライアントがプラグインごとのレガシー MCP サーバーではなく、UMCP エンドポイントに接続されているか

ルート変更後は Capability Mesh 設定を更新し、MCP クライアントを再接続または更新してください。

## エージェントツールが読み取り専用のガードレールを返す

これは期待される動作です。IIS の応答は、プロジェクトの変更が許可されていないことを意図的に示しています。

## パフォーマンスセルフチェックが乖離をレポートする

`iis.perf.last` から最新のパフォーマンス結果を確認するか、`iis.perf.run` を再実行してください。乖離は通常、現在のベクトルワークロード、バックエンド、またはチューニングが構成された予算を超えていることを意味します。

まずクエリの幅またはベクトルワークロードを下げてください。ターゲットマシン/プロジェクトプロファイルでの代表的な検証後にのみ予算を更新してください。

## レポートの確認場所

デフォルトの場所：

```text
Saved/InternalIndexService/reports
Saved/InternalIndexService/imports
Saved/InternalIndexService/agent_contracts
```
