# サードパーティソフトウェア

Unreal Capability Mesh は、サードパーティのソースコード、サードパーティのランタイムバイナリ、Node.js、Python、AI モデル、または単体の実行可能ファイルを同梱していません。

本プラグインは、JSON 解析、エディター UI、プロジェクトパス、モジュールのロード、および診断のために、Unreal Engine モジュールおよび標準の Unreal Engine API を使用します。

Fab サードパーティソフトウェア宣言: サードパーティソフトウェアの同梱なし。
