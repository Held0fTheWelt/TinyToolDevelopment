# Drittanbieter-Software

Unreal Capability Mesh bündelt keinen Quellcode von Drittanbietern, keine Laufzeitbinärdateien von Drittanbietern, kein Node.js, Python, KI-Modelle oder eigenständige ausführbare Dateien.

Das Plugin nutzt Unreal Engine Module und Standard-Unreal Engine-APIs für JSON-Parsing, Editor-UI, Projektpfade, Modulladen und Diagnosen.

Fab-Erklärung zu Drittanbieter-Software: Keine gebündelte Drittanbieter-Software.
