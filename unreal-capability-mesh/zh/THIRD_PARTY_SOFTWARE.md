# 第三方软件

Unreal Capability Mesh 未捆绑任何第三方源代码、第三方运行时二进制文件、Node.js、Python、AI 模型或独立可执行文件。

该插件使用 Unreal Engine 模块和标准 Unreal Engine API 进行 JSON 解析、编辑器 UI、项目路径、模块加载和诊断。

Fab 第三方软件声明：无捆绑第三方软件。
