# Software de terceros

Unreal Capability Mesh no incluye código fuente de terceros, binarios de tiempo de ejecución de terceros, Node.js, Python, modelos de IA ni ejecutables independientes.

El plugin utiliza módulos de Unreal Engine y las API estándar de Unreal Engine para procesamiento JSON, interfaz de usuario del editor, rutas de proyectos, carga de módulos y diagnósticos.

Declaración de software de terceros para Fab: sin software de terceros incluido.
