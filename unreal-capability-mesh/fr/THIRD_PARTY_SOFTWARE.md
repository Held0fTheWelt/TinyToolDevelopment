# Logiciels tiers

Unreal Capability Mesh n'embarque aucun code source tiers, aucun binaire d'exécution tiers, ni Node.js, Python, modèles d'IA ou exécutables autonomes.

Le plugin utilise les modules d'Unreal Engine et les API standard d'Unreal Engine pour l'analyse JSON, l'interface utilisateur de l'éditeur, les chemins de projet, le chargement de modules et les diagnostics.

Déclaration de logiciels tiers Fab : aucun logiciel tiers embarqué.
