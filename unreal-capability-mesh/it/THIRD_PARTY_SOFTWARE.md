# Software di terze parti

Unreal Capability Mesh non include codice sorgente di terze parti, binari di runtime di terze parti, Node.js, Python, modelli AI o eseguibili autonomi.

Il plugin utilizza i moduli di Unreal Engine e le API standard di Unreal Engine per il parsing JSON, l'interfaccia utente dell'editor, i percorsi del progetto, il caricamento dei moduli e la diagnostica.

Dichiarazione sui software di terze parti Fab: nessun software di terze parti incluso.
