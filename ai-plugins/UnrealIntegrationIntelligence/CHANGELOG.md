# Changelog

All notable changes to Unreal Integration Intelligence will be documented in this file.

## [1.1.3] - 2026-07-19

### Fixed
- Aligned the `uii.translation.evidence.v1` route output binding with its declared `evidence` capability port.
- Required the emitted schema discriminator and rejected unreadable or schema-incompatible UBI deep-export and compiler-diagnostic inputs before index construction.
- Normalized explicit and discovered upstream artifact paths to canonical absolute paths before reading and persistence.

### Changed
- Added the optional Translation-Evidence workflow to the machine-readable agent guide.
- Required embedded Blueprint/compiler objects and downstream integrity validation of all six referenced JSON artifacts.

## [1.1.2] - 2026-07-18

### Added
- Added `uii.translation.evidence.v1`, which combines UBI deep graph and compiler facts with UII-owned source/target C++ symbol and Reflection Surface indexes.

### Changed
- Missing `source_roots` is explicitly labelled as a current-target baseline warning rather than original-source evidence.

## [1.1.1] - 2026-07-12

### Added
- Added the machine-readable plugin guide for agent orientation.

## [1.1.0] - 2026-07-02

### Added
- Added DataTable and animation evidence to the System Dossier and retrieval-grade IIS handoff chunking.

## [1.0.0] - 2026-07-01

### Added
- Added runtime, editor, interface, and developer modules for Unreal project analysis, migration planning, and integration-intelligence workflows.
- Added evidence contracts, System Dossier generation, review packs, RAG-ready chunks, UCM route manifests, and local handoff metadata.

### Changed
- Promoted Unreal Integration Intelligence to the `In Publishment` 1.0.0 release line for Fab handoff preparation.
- Reconciled buyer documentation, public overview text, product images, and publication copy to the 1.0.0 in-publishment package state.

### Fixed
- Made the editor build rules depend on `UnrealIntegrationIntelligenceInterface` for dossier bridge output types.
