Internal Index Service

Internal Index Service is a local retrieval and context-pack plugin for Unreal Engine. It imports prepared project evidence, builds searchable local indexes, supports lexical/vector/hybrid search, and exposes read-only agent tool contracts.

Open the editor workflow from Tools -> AI -> Internal Index Service -> Open Internal Index Service.

Default generated data root:
Saved/InternalIndexService

MCP transport is provided by Unified MCP Server plus project Capability Mesh routes. IIS itself is retrieval-only and does not mutate project files or assets.
