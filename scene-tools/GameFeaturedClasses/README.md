# Game Featured Classes

> Not a verbatim copy of shipped docs. This online page is an overview and routing surface; shipped buyer docs stay in the plugin package.

Game Featured Classes (GFC) is a lightweight runtime plugin shell for project-specific featured gameplay classes. Version `1.0.1` ships the descriptor, packaging metadata, icon, changelog, and a runtime module boundary. Featured classes and the premium GameFeature Workbench remain target architecture (not yet available in this package).

## Get It / Routing

- Fab: Not listed yet
- Online docs URL (descriptor `DocsURL`): https://docs.tiny-tool-development.com/game-featured-classes/
- Package docs: shipped inside the plugin package as `Documentation/QUICKSTART.md`,
  `Documentation/UserManual.md`, `Documentation/SettingsReference.md`,
  `Documentation/TROUBLESHOOTING.md`, `Documentation/FAQ.md`, and
  `Documentation/THIRD_PARTY_SOFTWARE.md`.
- Category: Scene Tools
- Descriptor version: `1.0.1` (`EngineVersion` 5.4.0)

## Synergies & Bridges

The module shell loads on its own. Future optional integrations with Lightweight Dummy Actor System, Unreal Capability Mesh, or Project Intelligence Orchestrator are target architecture only and must never be treated as setup requirements for the shell. Synergy detail belongs here online (Fab Autark §11), not in the Fab package Quick Start.
