# Software de terceros

Log Level Editor **no incluye código fuente de terceros, binarios en tiempo de ejecución, modelos de IA, Node.js, Python ni ejecutables independientes**. Es un plugin de C++ para el editor de Unreal Engine que utiliza únicamente módulos de Unreal Engine y API estándar de Unreal (categorías de registro, comandos de consola, DataAssets, interfaz del editor).

No se requiere software externo, cuenta ni runtime adicional para instalar o utilizar el plugin.

**Declaración de software de terceros para Fab:** sin software de terceros incluido.
