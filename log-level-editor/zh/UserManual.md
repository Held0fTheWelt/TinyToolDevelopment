# 用户手册

本手册解释 LogLevelEditor 在编辑器中的日常工作流。

## 安装

1. 将插件添加到项目的 `Plugins` 文件夹中或通过 Fab 进行安装。
2. 在 **Edit > Plugins** 中启用 **LogLevelEditor**。
3. 如果 Unreal 提示重启，请重启编辑器。
4. 如果需要检查默认 DataAsset，请确认插件内容是否可见。

## 打开工具

通过 **Tools → Log Tools → Log Level Editor** 或可选的工具栏快捷方式打开 LogLevelEditor。插件作为可停靠选项卡打开，嵌入在编辑器工作区中。

## 首次扫描

打开工具时，它会扫描配置的位置以查找日志类别。

默认情况下专注于：

- 项目源码文件。
- 项目插件源码文件。

可选设置可以包含：

- 引擎插件源码文件。
- 引擎源码文件。

引擎扫描可能会比较耗时。仅在仪表板中确实需要引擎类别时才启用它们。

## 阅读列表

每行代表一个日志类别。

重要字段：

- 类别名称：Unreal 日志类别名称，例如 `LogTemp`。
- 检测到的默认值：尽可能从声明/定义宏中推断出的默认详细级别。
- 当前级别：Unreal 当前为已注册类别报告的详细级别。如果 Unreal 尚无法报告它，该行显示 `Unavailable`。首次扫描后，此值会定期刷新。
- 源码路径：扫描器找到该类别的具体位置（可用时）。

## 更改详细级别

1. 通过搜索/筛选找到类别。
2. 从该行的详细级别按钮中选择一个 Verbosity 值。
3. 插件执行 Unreal 控制台命令。
4. 仅在命令执行成功后才更新该行和 DataAsset。

常见选择：

- `Warning`：减少干扰，同时保留重要问题。
- `Log`：常规输出的常见默认值。
- `Verbose`：适用于诊断。
- `VeryVerbose`：非常详细的输出，通常是临时的。
- `NoLogging`：在 Unreal 允许的范围内最大程度地静音某个类别。

## 恢复默认值

当选择的详细级别与检测到的默认值匹配时，插件将自动移除该类别的持久重写。这使得 DataAsset 仅关注真实的重写项。

如果未检测到默认值，请将该行视为参考信息，并手动重置为项目期望的值。

## 持久重写

持久值存储在配置的 `ULogLevelDataAsset` 中。

推荐工作流：

1. 在默认 DataAsset 中保留项目级有意的重写。
2. 仅当这些重写符合团队规范时才将其纳入版本控制。
3. 避免将临时的调试干扰保存到共享的版本控制中。
4. 使用临时隐藏设置来保持个人 UI 界面的专注。

## 启动应用

保存的重写项会在编辑器启动期间重新应用。模块会等待直到引擎能够接受控制台命令，并在启动过早时重试少量次数。

## 隐藏类别

永久隐藏列表：

- 存储在配置中。
- 适用于很少需要在工具中出现的类别。

临时隐藏列表：

- 挥发性存储（Transient）。
- 适用于单个编辑器会话期间的局部聚焦。
- 不会写入配置。

## 设置

在注册的编辑器设置/项目设置位置下打开插件设置。

关键设置：

- `LogLevelDataAsset`：用于存储持久重写的 DataAsset。
- `bAutoSaveLogLevelDataAsset`：在进行有意的重写更改后自动保存资产。
- `bShowToolbarButton`：显示或隐藏工具栏快捷方式。
- `bAlsoListEnginePluginChannels`：在扫描中包含引擎插件类别。
- `bAlsoListEngineSourceChannels`：在扫描中包含引擎源码类别。
- `LogChannelsToHide`：永久隐藏的类别。
- `LogChannelsToHideTemporary`：仅限会话隐藏的类别。

## 推荐的团队工作流

团队使用规范：

1. 在版本控制中维护默认 DataAsset。
2. 仅保存稳定的项目规范重写。
3. 不要提交本地的临时隐藏项。
4. 在项目的 Wiki 中记录支持/调试预设。

## 移除插件

在移除插件前：

1. 重置您关心的任何临时日志详细级别更改。
2. 如果不再使用插件 DataAsset，请删除或忽略它。
3. 禁用插件并重启编辑器。

插件不会修改日志类别的源码声明，因此移除不需要清理 C++ 代码。
