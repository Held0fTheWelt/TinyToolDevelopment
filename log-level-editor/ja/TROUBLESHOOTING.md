# トラブルシューティング

## ツールに自分のカテゴリが表示されない

以下を確認してください。

- カテゴリがスキャン対象のソースパス内で宣言または定義されているか。
- 拡張子が `.h`、`.hpp`、`.cpp`、`.inl` のいずれかであるか。
- 永久または一時的な非表示設定によって隠されていないか。
- スキャンが完了しているか、あるいは処理中であるか。
- マクロがサポート対象の Unreal ログマクロ形式であるか。

## デフォルトの詳細度が不足している、または間違っている

スキャナーは認識可能なマクロ引数からのみデフォルトを推測できます。一部のカテゴリは空またはフォールバックのデフォルトで表示される場合があります。

解決策:

- 可能な限り標準的な Unreal マクロ形式を使用します。
- 既知の値が必要な場合は、永続オーバーライドを追加します。

## 詳細度を変更しても何も起こらない

考えられる原因:

- ロードされたモジュールによってカテゴリがまだ登録されていない。
- Unreal がコンソールコマンドを拒否した。
- エディタコマンドの後にランタイムコードが再度カテゴリを変更した。

Output Log で `LogLogLevelEditor` メッセージを確認してください。

## 保存された詳細度が起動時に適用されない

以下を確認してください。

- `LogLevelDataAsset` が有効なアセットを指しているか。
- DataAsset にオーバーライドエントリーが含まれているか。
- 起動時の再試行再生が実行される時点でカテゴリが存在しているか。

## DataAsset にエントリーが多すぎる

DataAsset には意図的なオーバーライドのみが含まれるべきです。行を検出されたデフォルトにリセットして、不要なエントリーを削除してください。

## 一時非表示の値が再表示された

一時非表示の値はセッション限定（Transient）であり、セッション間で保持されません。永久に非表示にするには `LogChannelsToHide` を使用してください。

## スキャンに時間がかかりすぎる

必要がない限り、エンジンプラグインおよびエンジンソースのスキャンを無効にしてください。

推奨される通常設定:

```text
bAlsoListEnginePluginChannels = false
bAlsoListEngineSourceChannels = false
```

## Output Log が依然として騒がしい

一部のシステムは複数のカテゴリを通じてログを出力することがあります。関連するカテゴリの接頭辞を検索し、関連する各チャンネルを調整してください。

## プラグインは開くが DataAsset のオーバーライドが表示されない

スキャナーと DataAsset は独立しています。

- スキャナー: 利用可能なカテゴリを発見します。
- DataAsset: 永続オーバーライドを保存します。

永続オーバーライドが設定されていない場合、DataAsset が空であることは正常です。

## ソースコントロールで DataAsset が変更済みと表示され続ける

永続オーバーライドを変更した可能性があります。変更をチーム方針として維持するか、コミット前に行をデフォルトにリセットしてください。

## 収集すべきサポート情報

問題を報告する際は、以下を含めてください。

- Unreal Engine のバージョン。
- プラグインのバージョン。
- エンジンソース / プラグインのスキャンが有効かどうか。
- ログカテゴリ宣言の例。
- 関連する `LogLogLevelEditor` の出力。
