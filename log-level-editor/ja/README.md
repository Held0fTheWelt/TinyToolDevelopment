# LogLevelEditor ドキュメント

LogLevelEditor は、ログカテゴリを検出し、専用のエディタダッシュボードからそれらの詳細度（Verbosity）を変更するための Unreal Engine エディタプラグインです。日常業務におけるノイズの多いログを削減し、デバッグ時に一時的に診断チャンネルの詳細度を上げ、意図したオーバーライドを DataAsset に保存するのに役立ちます。

コアアクションは **Scan**、**Set Verbosity**、**Hide Category** です。

本フォルダには、プラグインに付属する完全なドキュメントが含まれています。

## クイックワークフロー

1. プラグインを有効化し、促されたらエディタを再起動します。
2. **Tools → Log Tools → Log Level Editor** またはオプションのツールバーショートカットから Log Level Editor タブを開きます。
3. スキャナーにプロジェクトおよびプラグインのログカテゴリを検出させます。
4. 検索と非表示設定を使用して、重要なチャンネルに絞り込みます。
5. 行の詳細度ボタンからカテゴリの詳細度を変更します。
6. 意図した変更である場合は、設定された `ULogLevelDataAsset` にオーバーライドを永続化します。
7. 検出されたデフォルト値を再度選択して、カテゴリを検出されたデフォルトにリセットします。

## ツールが変更する内容

本プラグインは、以下の形式で Unreal のコンソールコマンドを適用します。

```text
Log <CategoryName> <VerbosityName>
```

ログカテゴリのソースコードにおける宣言を変更することはありません。永続的な変更は設定された DataAsset に保存され、エンジンがコンソールコマンドを受け入れられる準備が整った後にエディタモジュールによって再生されます。

## サポートされている詳細度（Verbosity）名

共有詳細度ヘルパーは、Unreal の標準ログレベルをサポートしています。

- `NoLogging`
- `Fatal`
- `Error`
- `Warning`
- `Display`
- `Log`
- `Verbose`
- `VeryVerbose`

ユーザーが UI 上の変更をコンソールコマンドの挙動に対応させやすいよう、エディタは Unreal のログ設定で表示されるものと同じ名称を意図的に使用しています。

## 安全性モデル

LogLevelEditor はユーザーに偽の状態を表示しないように設計されています。

- カテゴリがクエリ可能な場合、`Current` ラベルは Unreal のランタイム状態から取得されます。
- UI の状態は、コンソールコマンドが成功した後にのみ更新されます。
- 選択された値が検出されたデフォルトと一致する場合、永続オーバーライドは自動的に削除されます。
- 一時的な非表示設定はセッション限定（Transient）であり、設定ファイルには書き込まれません。
- 保存されたオーバーライドは起動時にカテゴリごとの再試行ロジックを伴って適用されます（モジュール起動時にはエディタがコンソールコマンドを受け入れられない場合があるため）。

## 代表的なユースケース

- プラグインを有効に保ったまま、ログ出力の多いプラグインからのスパムを削減する。
- デバッグ時に、ゲームプレイ、ビルド、アセット、またはエディタサブシステムの詳細度を一時的に `Verbose` に引き上げる。
- 問題の調査後にクリーンなデフォルト状態に復元する。
- 意図したプロジェクト全体の詳細度オーバーライドを含むチーム用の DataAsset を共有する。
- スキャンを高速かつ関連性の高い状態に保つため、設定によってエンジンとプロジェクトのカテゴリを分離する。

## 重要な制限事項

- ログカテゴリはソースコード内に存在するか、ランタイム/エディタモジュールによって既に登録されている必要があります。
- ソースコードのスキャンは、一般的な Unreal マクロからのみデフォルト値を推enc（推測）できます。
- エディタが保存されたオーバーライドを適用した後でも、ランタイムコードによって詳細度が変更される可能性があります。
- 出荷用ビルド（Shipping build）は本エディタプラグインの影響を受けません。

## 法的注意事項

LogLevelEditor はエディタの生産性向上ツールです。Unreal Engine のログ記録セマンティクス、エンジンソースコード、またはプロジェクトのライセンス条項を変更することはありません。
