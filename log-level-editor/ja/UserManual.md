# ユーザーマニュアル

本マニュアルでは、LogLevelEditor の日常的なエディタワークフローについて説明します。

## インストール

1. プロジェクトの `Plugins` フォルダにプラグインを追加するか、Fab 経由でインストールします。
2. **Edit > Plugins** で **LogLevelEditor** を有効にします。
3. 促された場合はエディタを再起動します。
4. デフォルトの DataAsset を確認したい場合は、プラグインコンテンツが表示されていることを確認します。

## ツールを開く

**Tools → Log Tools → Log Level Editor** またはオプションのツールバーショートカットから LogLevelEditor を開きます。プラグインはドッキング可能なエディタタブとして開くため、ワークスペース内に保持されます。

## 初回スキャン

ツールを開くと、設定された場所からログカテゴリをスキャンします。

デフォルトでは以下に焦点を当てます。

- プロジェクトのソースファイル。
- プロジェクトプラグインのソースファイル。

オプションの設定により以下を含めることができます。

- エンジンプラグインのソースファイル。
- エンジンのソースファイル。

エンジンのスキャンは時間がかかる場合があります。ダッシュボードにエンジンのカテゴリがどうしても必要な場合にのみ有効にしてください。

## リストの読み方

各行は 1 つのログカテゴリを表します。

重要なフィールド:

- カテゴリ名: Unreal のログカテゴリ名（例: `LogTemp`）。
- 検出されたデフォルト: 可能であれば宣言/定義マクロから推測されたデフォルトの詳細度。
- 現在のレベル: 登録されているカテゴリに対して Unreal が現在レポートしている詳細度。Unreal がまだレポートできない場合、行には `Unavailable` と表示されます。初回スキャン後、この値は定期的に更新されます。
- ソースパス: スキャナーがカテゴリを発見した場所（利用可能な場合）。

## 詳細度（Verbosity）の変更

1. 検索 / フィルタリングを使用してカテゴリを見つけます。
2. 行の詳細度ボタンから値を選択します。
3. プラグインが Unreal コンソールコマンドを実行します。
4. コマンド実行が成功した場合にのみ、行と DataAsset が更新されます。

一般的な選択肢:

- `Warning`: 重要問題を維持しつつノイズを減らす。
- `Log`: 通常出力用の一般的なデフォルト。
- `Verbose`: 診断に有用。
- `VeryVerbose`: 非常に詳細な出力（通常は一時的）。
- `NoLogging`: Unreal が許可する限りカテゴリを消音する。

## デフォルトの復元

選択された詳細度が検出されたデフォルトと一致する場合、プラグインはそのカテゴリの永続オーバーライドを削除します。これにより、DataAsset は重複したデフォルト値ではなく、実際のオーバーライドのみに焦点を当てることができます。

デフォルトが検出されなかった場合は、その行を情報として扱い、プロジェクトが期待する値に手動でリセットしてください。

## 永続オーバーライド

永続的な値は設定された `ULogLevelDataAsset` に保存されます。

推奨ワークフロー:

1. プロジェクト全体の意図的なオーバーライドはデフォルトの DataAsset に保持します。
2. それらのオーバーライドがチームの方針である場合にのみ、アセットをバージョン管理に含めます。
3. 一時的なデバッグノイズを共有ソースコントロールに保存しないようにします。
4. 個人レベルでの画面の絞り込みには一時的な非表示設定を使用します。

## 起動時適用

保存されたオーバーライドはエディタ起動時に再生されます。モジュールはエンジンがコンソールコマンドを受け入れられるようになるまで待機し、起動初期すぎる場合は少回数再試行します。

## カテゴリの非表示

永久非表示リスト:

- 設定ファイルに保存されます。
- ツール上で滅多に表示する必要のないカテゴリに役立ちます。

一時非表示リスト:

- セッション限定（Transient）で保存されます。
- 1 つのエディタセッション中のローカルな集中に役立ちます。
- 設定ファイルには書き込まれません。

## 設定

プラグイン設定はエディタ設定 / プロジェクト設定から開くことができます。

主要な設定:

- `LogLevelDataAsset`: 永続オーバーライドを保存する DataAsset。
- `bAutoSaveLogLevelDataAsset`: 意図的なオーバーライド変更後にアセットを自動保存します。
- `bShowToolbarButton`: ツールバーショートカットの表示/非表示を切り替えます。
- `bAlsoListEnginePluginChannels`: エンジンプラグインのカテゴリをスキャンに含めます。
- `bAlsoListEngineSourceChannels`: エンジンソースのカテゴリをスキャンに含めます。
- `LogChannelsToHide`: 永久に非表示にするカテゴリ。
- `LogChannelsToHideTemporary`: セッション限定で非表示にするカテゴリ。

## チームでの推奨ワークフロー

チームで使用する場合:

1. デフォルトの DataAsset をソースコントロールで管理します。
2. 安定したプロジェクト方針のオーバーライドのみを保存します。
3. ローカルな一時非表示設定をコミットしないでください。
4. サポート / デバッグ用のプリセットをプロジェクト wiki にドキュメント化します。

## プラグインの削除

プラグインを削除する前に:

1. 一時的なログ詳細度の変更をリセットします。
2. プラグインの DataAsset が使用されなくなる場合は、削除または無視します。
3. プラグインを無効化し、エディタを再起動します。

プラグインはログカテゴリのソースコード宣言を変更しないため、削除時に C++ 側のクリーンアップ作業は不要です。
