# Software von Drittanbietern

Log Level Editor **enthält keinen Quellcode von Drittanbietern, keine Runtime-Binärdateien, KI-Modelle, Node.js, Python oder eigenständige ausführbare Dateien**. Es handelt sich um ein C++ Unreal Engine Editor-Plugin, das ausschließlich Unreal Engine-Module und Standard-Unreal-APIs nutzt (Log-Kategorien, Konsolenbefehle, DataAssets, Editor-UI).

Es ist keine externe Software, kein Konto und keine zusätzliche Runtime erforderlich, um das Plugin zu installieren oder zu verwenden.

**Fab-Erklärung zu Software von Drittanbietern:** Keine mitgelieferte Software von Drittanbietern.
