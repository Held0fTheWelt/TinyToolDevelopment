# Software di terze parti

Log Level Editor **non include codice sorgente di terze parti, binari a runtime, modelli di IA, Node.js, Python o eseguibili autonomi**. Si tratta di un plugin C++ per l'editor di Unreal Engine che utilizza esclusivamente moduli di Unreal Engine e API standard di Unreal (categorie di log, comandi di console, DataAsset, interfaccia dell'editor).

Nessun software esterno, account o runtime è richiesto per installare o utilizzare il plugin.

**Dichiarazione Fab sul software di terze parti:** nessun software di terze parti incluso.
