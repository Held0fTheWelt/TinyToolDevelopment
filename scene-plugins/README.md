# Scene Plugins

This category collects Tiny Tool scene-oriented Unreal plugins that are not just editor utilities. The category exists so the public docs can separate scene-facing runtime packages from the broader scene-tools landing area.

## Game Featured Classes

Game Featured Classes (GFC) has a public landing page at [docs.tiny-tool-development.com/game-featured-classes/](https://docs.tiny-tool-development.com/game-featured-classes/). It is a lightweight runtime shell for featured gameplay classes, and the shipped buyer docs remain inside the plugin package as `Documentation/QUICKSTART.md`, `Documentation/UserManual.md`, `Documentation/SettingsReference.md`, `Documentation/TROUBLESHOOTING.md`, `Documentation/FAQ.md`, and `Documentation/THIRD_PARTY_SOFTWARE.md`.

## Lightweight Dummy Actor System

Lightweight Dummy Actor System (LDAS) has a public landing page at [docs.tiny-tool-development.com/lightweight-dummy-actor-system/](https://docs.tiny-tool-development.com/lightweight-dummy-actor-system/). It provides autonomous dummy-actor representation with readiness gates, promotion and demotion policy, diagnostics, an editor inspector, and a validate commandlet, while the shipped buyer docs stay in the plugin package.
