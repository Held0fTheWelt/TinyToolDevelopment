# FAQ

## What does this bridge do?

SmartContentDiet UII Migration Bridge lets SmartContentDiet surface migration and upgrade-impact advice from Unreal Integration Intelligence handoff artifacts.

## Is this a standalone product?

No. It is an optional bridge package for projects that already use SmartContentDiet and Unreal Integration Intelligence together.

## Does it perform migrations?

No. The bridge surfaces migration advice and evidence. It does not authorize, generate, or apply project mutations.

## Does it replace Unreal Integration Intelligence?

No. Unreal Integration Intelligence remains the evidence extraction and handoff owner. The bridge only adapts its migration evidence into SmartContentDiet-facing review context.

## What engine versions are supported?

The bridge source targets Unreal Engine 5.4 and should be packaged and verified across the configured release matrix before publication.
