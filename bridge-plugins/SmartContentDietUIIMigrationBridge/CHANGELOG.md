## [1.0.1] - 2026-06-16

### Added
- Added the optional bridge plugin for Smart Content Diet and Unreal Integration Intelligence projects.
- Added the `uii-migration` migration advisor provider adapter for SCD workflows.
- Added handoff availability checks and translation of UII guardrails into advisory SCD migration findings.
- Added module and dependency metadata for SmartContentDietInterface and UnrealIntegrationIntelligenceInterface.
- Added buyer-facing setup, boundary, status, and support notes in the root README.
