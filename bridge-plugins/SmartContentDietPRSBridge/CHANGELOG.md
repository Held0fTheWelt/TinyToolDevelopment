## [1.0.1] - 2026-06-16

### Added
- Added the optional bridge plugin for Smart Content Diet and Project Restructure Service projects.
- Added the `FSCDToPRSPlacementAdapter` path for converting reviewed SCD placement proposals into PRS plans.
- Added read-only SCD health context helpers for PRS placement evaluation.
- Added tests for SCD-to-PRS adapter behavior.
- Added buyer-facing setup, guardrail, status, and support notes in the root README.
