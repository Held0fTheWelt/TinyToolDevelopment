# FAQ

## What does this bridge do?

SmartContentDiet PRS Bridge connects SmartContentDiet placement review evidence with Project Restructure Service dry-run, apply, rollback, and health-query surfaces.

## Is this a standalone product?

No. It is an optional bridge package for projects that intentionally use SmartContentDiet and Project Restructure Service together.

## Does the bridge move assets by itself?

No. It adapts review and placement evidence. Any restructuring action must stay in the Project Restructure Service approval, dry-run, apply, and rollback workflow.

## Does it replace either core plugin?

No. SmartContentDiet remains the asset-health review owner, and Project Restructure Service remains the restructuring owner.

## What engine versions are supported?

The bridge source targets Unreal Engine 5.4 and should be packaged and verified across the configured release matrix before publication.
