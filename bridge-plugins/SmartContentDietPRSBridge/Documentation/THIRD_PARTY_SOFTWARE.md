# Third-Party Evidence

SmartContentDiet PRS Bridge does not bundle third-party source libraries, model weights, cloud services, SDK redistributables, or executable dependencies.

The bridge compiles against Unreal Engine and the public APIs of Smart Content Diet and Project Restructure Service. Validation, dry-run, apply, and rollback governance remain with Project Restructure Service.

Evidence notes:

- No `Source/ThirdParty` folder is shipped in this example project.
- No vendor binaries, model weights, or external service clients are shipped by the bridge.
- Runtime prerequisites are the companion Tiny Tool Development plugins named in the README.
