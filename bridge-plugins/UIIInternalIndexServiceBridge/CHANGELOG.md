## [1.0.0] - 2026-06-16

### Added
- Added the optional bridge plugin for docking Unreal Integration Intelligence handoff contracts into Internal Index Service.
- Added runtime and editor modules for handoff import, Blueprint access, Python/editor wrappers, and menu entry points.
- Added documentation for quickstart, Blueprint usage, integration, source overview, troubleshooting, buyer guidance, and release checks.
- Added evidence-only guardrails so the bridge imports and indexes prepared evidence without authorizing migration, patch generation, or project mutation.
