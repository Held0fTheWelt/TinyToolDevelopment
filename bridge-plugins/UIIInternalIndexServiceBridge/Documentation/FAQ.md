# FAQ

## What does this bridge do?

UII Internal Index Service Bridge imports Unreal Integration Intelligence handoff contracts into Internal Index Service so prepared evidence can be catalogued, retrieved, and checked by IIS workflows.

## Is this a standalone product?

No. It is an optional bridge for projects that already use Unreal Integration Intelligence or a compatible handoff producer together with Internal Index Service.

## Does it extract Unreal evidence?

No. UII or another compatible producer writes the handoff contract. The bridge only validates and docks that prepared evidence into IIS.

## Does it mutate project assets?

No. The bridge imports evidence and writes IIS reports. It does not patch, migrate, copy, or delete Unreal assets or source files.

## What engine versions are supported?

The bridge source targets Unreal Engine 5.4 and should be packaged and verified across the configured release matrix before publication.
