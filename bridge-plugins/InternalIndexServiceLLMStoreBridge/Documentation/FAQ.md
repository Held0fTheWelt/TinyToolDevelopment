# FAQ

## Is this a Fab product?

No. IIS LLM Store Bridge is a free companion example project. It is parked under Example Projects and is outside the active Fab publication framework.

## Does it replace Unreal Capability Mesh?

No. UCM remains the preferred integration layer for governed cross-product workflows. This bridge is a narrow no-UCM adapter and reference implementation.

## Which plugins are required?

Internal Index Service and LLM Store must both be enabled. The bridge only adapts IIS embedding executor requests to LLM Store embedding routes.

## Does it bundle third-party software?

No. The bridge does not bundle third-party source libraries, model weights, services, or executable dependencies.
