## [1.0.1] - 2026-06-16

### Added
- Added the optional bridge plugin for Smart Content Diet and Internal Index Service projects.
- Added the `iis-similarity` semantic similarity provider adapter for SCD workflows.
- Added health-evidence JSONL translation into IIS prepared chunks with sensitivity and chunk-kind labelling.
- Added module and dependency metadata for SmartContentDietInterface and InternalIndexServiceInterface.
- Added buyer-facing setup, boundary, status, and support notes in the root README.
