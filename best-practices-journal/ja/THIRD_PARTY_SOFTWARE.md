# サードパーティソフトウェア

Best Practices Journal は、サードパーティのランタイム、モデルプロバイダー、データベースサーバー、または外部の実行可能ファイルを同梱していません。

オプションの SQLite または Postgres ワークフローは、ストレージプロファイルおよび外部環境の選択肢です。これらがプラグインパッケージ内にサードパーティソフトウェアとして同梱されることはありません。

プロジェクトが SQLite、Postgres、IIS、UCM、UCI、PRS、またはその他のオプションのエコシステムコンポーネントを使用する場合、そのコンポーネントは外部プロジェクトまたはスタジオの選択にとどまります。BPJ の出荷パッケージは、それらのコンポーネントなしでも JSON アーティファクトを開き、検証し、インポートし、エクスポートし、レビューできなければなりません。

オプションのプロバイダーおよびコンシューマーは統合サーフェスであり、同梱ソフトウェアではありません。それらが存在しない場合は、ステータスや診断としてのみ表示されるべきであり、BPJ の起動失敗や初回使用時のエラーとなるべきではありません。
