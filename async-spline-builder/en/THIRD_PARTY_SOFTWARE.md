# Third-Party Software

Async Spline Builder **bundles no third-party source code, runtime binaries, AI models, Node.js,
Python, or standalone executables**. It is a C++ Unreal Engine plugin (runtime + editor modules)
that uses only Unreal Engine modules and standard Unreal APIs (splines, spline mesh components,
procedural meshes, landscape, editor UI).

No external software, account, or runtime is required to install or use the plugin. You supply your
own road/wall meshes from your project content.

**Fab third-party software declaration:** no bundled third-party software.
