# Software di terze parti

Async Spline Builder **non include codice sorgente di terze parti, binari runtime, modelli di IA, Node.js, Python o eseguibili autonomi**. Si tratta di un plugin C++ per Unreal Engine (moduli runtime + editor) che utilizza esclusivamente moduli Unreal Engine e API standard di Unreal (spline, componenti mesh spline, mesh procedurali, paesaggio, UI dell'editor).

Non è richiesto alcun software esterno, account o runtime per installare o utilizzare il plugin. L'utente fornisce le proprie mesh stradali/muri dai contenuti del proprio progetto.

**Dichiarazione software di terze parti Fab:** nessun software di terze parti incluso.
