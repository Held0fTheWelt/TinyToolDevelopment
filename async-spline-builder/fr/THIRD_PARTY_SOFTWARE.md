# Logiciels tiers

Async Spline Builder **ne regroupe aucun code source tiers, binaire runtime, modèle IA, Node.js, Python ou exécutable indépendant**. Il s'agit d'un plugin C++ Unreal Engine (modules runtime + éditeur) utilisant uniquement les modules Unreal Engine et les API Unreal standard (splines, composants de maillage de spline, maillages procéduraux, paysage, UI d'éditeur).

Aucun logiciel externe, compte ou runtime n'est requis pour installer ou utiliser le plugin. Vous fournissez vos propres maillages de route/mur à partir du contenu de votre projet.

**Déclaration de logiciels tiers Fab :** aucun logiciel tiers regroupé.
