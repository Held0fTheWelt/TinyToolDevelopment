# Software von Drittanbietern

Async Spline Builder **bündelt keinen Quellcode, keine Laufzeit-Binärdateien, keine AI-Modelle, kein Node.js, kein Python und keine eigenständigen ausführbaren Dateien von Drittanbietern**. Es ist ein C++ Unreal Engine Plugin (Laufzeit- + Editor-Module), das nur Unreal Engine Module und Standard-Unreal-APIs (Splines, Spline-Mesh-Komponenten, prozedurale Meshes, Landschaft, Editor-UI) verwendet.

Es ist keine externe Software, kein Konto und keine externe Laufzeit erforderlich, um das Plugin zu installieren oder zu verwenden. Sie stellen Ihre eigenen Straßen-/Wand-Meshes aus Ihren Projektinhalten bereit.

**Fab-Erklärung zu Drittanbietersoftware:** Keine gebündelte Software von Drittanbietern.
