# 第三方软件

Async Spline Builder **未捆绑任何第三方源代码、运行时二进制文件、AI 模型、Node.js、Python 或独立可执行文件**。它是一个 C++ Unreal Engine 插件（运行时 + 编辑器模块），仅使用 Unreal Engine 模块和标准 Unreal API（样条线、样条网格体组件、程序化网格体、地形、编辑器 UI）。

安装或使用本插件不需要外部软件、帐户或运行时。您从项目中自行提供道路/墙壁网格体。

**Fab 第三方软件声明：** 无捆绑的第三方软件。
