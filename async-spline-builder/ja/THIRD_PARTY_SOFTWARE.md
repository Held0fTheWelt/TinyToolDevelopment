# サードパーティ製ソフトウェア

Async Spline Builder には、**サードパーティ製のソースコード、ランタイムバイナリ、AI モデル、Node.js、Python、スタンドアロン実行可能ファイルは一切バンドルされていません**。これは、Unreal Engine モジュールおよび標準の Unreal API（スプライン、スプラインメッシュコンポーネント、プロシージャルメッシュ、ランドスケープ、エディタ UI）のみを使用する C++ Unreal Engine プラグイン（ランタイム＋エディタモジュール）です。

プラグインのインストールや使用に、外部ソフトウェア、アカウント、ランタイムは必要ありません。道路/ウォールメッシュはプロジェクトコンテンツからご自身で用意してください。

**Fab サードパーティ製ソフトウェア宣言:** バンドルされたサードパーティ製ソフトウェアはありません。
