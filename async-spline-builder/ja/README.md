# Async Spline Builder ドキュメント

Async Spline Builder は、大規模なエディタフリーズを引き起こすことなく、道路、レーストラック、パイプ、レール、壁、および側撮オブジェクトのスプラインメッシュを生成します。同期ビルド、エディタ非同期バッチ処理、ランタイム非同期バッチ処理、セグメントごとのメッシュプラン、オプションのグランドウォール、スタントギャップ、ドロップウォール、スプラインポイントデータアセット、エディタ専用のランドスケープ高さ変形＋加算レイヤーペイントをサポートしています。

このフォルダには、プラグインに同梱されているドキュメントが含まれています。

## クイックワークフロー

1. プラグインを有効にし、必要に応じてエディタを再起動します。
2. **Tools > Track Tools > Async Spline Builder** を開きます。
3. ワークフローパネルから `ASplineGeneratingActor` を配置または選択します。
4. パネルのセットアップセクションで `MainMesh` を割り当てます。
5. ビューポートで `TrackSpline` のポイントを編集します。
6. 即時ビルドには **Build Now**、非同期バッチ処理には **Rebuild** を使用します。
7. 高度なセグメントごとの編集の前に、セグメントヘルパーを使用してセグメントごとの行を作成します。
8. オプション: Details パネルでグランドウォールを有効にし、トレースオブジェクトタイプを構成します。
9. オプション: ランドスケープを割り当て、**Deform Height** を実行した後、加算重量ペイントのために **Paint Layer** を実行します（Actor 上に `PaintLayer` が必要）。

## 主な機能

- スプラインに沿った道路またはトラックのメッシュ生成。
- レイアウト、アンカー、セグメント用のデザイナーコントロールを備えた、ネイティブなルート/レイアウトポイント作成のための Track Shape Editor。
- ルート関係を信頼する前に、パッシブな `PitEntry`、`PitExit`、`Link`、`ServiceAccess`、またはカスタムコネクタメタデータをレビューするための Validate Layout Connectors。
- 隠されたメッシュブランチを作成せずに、パッシブなレイアウト関係レコードを追加または更新するための Apply Layout Connector。
- `SegmentsPerTick` によるエディタ非同期リビルド。
- ネクストティックタイマーポンプを使用したランタイム非同期リビルド。
- セグメントごとのメッシュ選択とメッシュ長計画。
- ガードレール、バリア、フェンス、パイプ、または詳細メッシュ用の開始、中間、終了の追加メッシュ。
- 道路および側面メッシュを抑制するスタントギャップ。
- 高さステップ間のドロップ領域およびプロシージャルドロップウォール。
- 地形またはその他の構成されたオブジェクトタイプまで下にトレースするプロシージャルグランドウォール。
- 古い配列やコンストラクションリビルドに耐える、タグベースの生成コンポーネントクリーンアップ。
- `USplinePointListAsset` を通じたスプラインポイントの保存/読み込み。
- エディタ専用のランドスケープ高さ変形＋加算グローバルレイヤーペイント。
- 最もリスクの高い挙動に対する自動化テスト。

## サポートされているランタイムポジション

ランタイムモジュールには、Actor、スプラインメッシュ生成、グランドウォール生成、ドロップウォール生成、データアセットアクセス、およびランタイム非同期ポンプが含まれています。

エディタモジュールには、ワークフローパネル、エディタ専用のランドスケープ変形とレイヤーペイント、およびエディタ選択ヘルパーが含まれています。パッケージ化されたゲームはスプラインメッシュとプロシージャルウォールを構築できますが、ランドスケープの高さ/重量の編集とワークフローパネルはエディタ専用です。

## エディタワークフローパネル

プライマリなエディタサーフェスは **Tools > Track Tools > Async Spline Builder** です。共通のワークフローを **Build**、**Segments**、**Terrain** の各タブにグループ化し、検証ステータスを隠すことなく日常のタスクをコンパクトに保ちます。

ルートにネイティブなポイント/レイアウト作成が必要な場合は Track Shape Editor を使用し、ピットロード、サービスアクセス、または代替ルートに明示的な関係メタデータが必要な場合はレイアウトコネクタコントロールを使用します。

日常業務にはパネルを使用します。セグメントごとの追加メッシュ配列、詳細なウォール UV 設定、トレースオブジェクト配列、カスタムコリジョン設定、実験的フィールドなどの高度な生フィールドには Unreal Details パネルを使用します。

## 重要な制限事項

- ランドスケープ: `PaintLayer` が設定されている場合の高さ変形＋**加算グローバル**レイヤー重量ペイント（`PaintLandscapeLayerNow` またはパネルの **Paint Layer**）。置換/クリアペイントモードは実装されていません。
- ランドスケープ変形は一回限りのエディタ操作であり、すべてのトラックリビルドの自動ステップではありません。
- 複雑なプロダクションランドスケープには、特に急カーブ、非常にかんみな地形、混合されたセグメントごとのウォール設定において、引き続き手動の QA が必要です。
- ランタイム非同期自動化は決定論的なテストフックを通じてカバーされています。リリース用マップには、完全な PIE タイマーワールド統合パスを推奨します。

## 検証

ローカルパッケージ検証パスを行うには、プロジェクトのエディタターゲットをビルドし、Unreal の Automation ツールから AsyncSplineBuilder 自動化グループを実行します。メンテナ固有のコマンドパスは、出荷される購入者パッケージではなく、ローカルのリリースノートに保持してください。

## 推奨される最初のプロダクションパス

最初に短いオープンテストスプラインを使用し、次に閉ループ、最後に実際のトラックを使用します。`bUseAsyncBuild` を有効にし、`SegmentsPerTick = 2` から開始して、エディタの応答性を確認した後にのみ増やします。スナップやグランドウォールを有効にする前にトレースオブジェクトタイプを構成してください。検証は古いジオメトリを破壊し、有効な代替を作成しないビルドを意図的にブロックするためです。
