# Software de terceros

Async Spline Builder **no incluye código fuente de terceros, binarios en tiempo de ejecución, modelos de IA, Node.js, Python ni ejecutables independientes**. Es un complemento en C++ para Unreal Engine (módulos en tiempo de ejecución + editor) que utiliza únicamente módulos de Unreal Engine y API estándar de Unreal (splines, componentes de malla spline, mallas procedimentales, terreno, interfaz de usuario del editor).

No se requiere ningún software externo, cuenta ni tiempo de ejecución para instalar o usar el complemento. Usted proporciona sus propias mallas de carretera/muro a partir del contenido de su proyecto.

**Declaración de software de terceros de Fab:** ningún software de terceros incluido.
