# Engine Plugins

This category contains Unreal Engine infrastructure plugins that provide shared editor/runtime contracts, protocol hosts, extension points, or project-level engine services.

## Products

- [Asset Loader Studio](AssetLoaderStudio/README.md) - structured asset-data workspace, dependency inspection, governed preview/apply, and optional UCM/UMCP reach paths.
- [Geo Provider Store](GeoProviderStore/README.md) - advanced-preview provider gateway for geospatial APIs, local datasets, request policy, provenance, and reports.
- [Lightning](Lightning/README.md) - advanced-preview data-oriented runtime core plus a separately
  bounded Unreal owner and Actor bridge.

## Notes

Engine plugins in this category are not AI plugins or gameplay systems. They usually provide shared infrastructure that other products, UCM setup, optional no-UCM bridge plugins, or local workflows can build on.
