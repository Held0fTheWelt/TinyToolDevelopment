# 第三方软件

Naming Convention Utility **不包含任何第三方源代码、可执行二进制文件、AI 模型、Node.js、Python 或独立的外部程序**。它是一个纯 C++ 编写的 Unreal Engine 编辑器插件，完全依赖 Unreal Engine 标准模块和 API（资产注册表、资产重命名工具、DataAsset、DataTable、编辑器 UI）。`Resources/` 文件夹中的 CSV 和 JSON 文件仅作为配置数据使用。

安装或使用本插件不需要任何外部软件、账户或额外的运行时环境。

**Fab 第三方声明：** 未包含任何第三方软件。
