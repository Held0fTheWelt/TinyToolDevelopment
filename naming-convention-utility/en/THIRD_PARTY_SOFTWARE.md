# Third-Party Software

Naming Convention Utility **bundles no third-party source code, runtime binaries, AI models,
Node.js, Python, or standalone executables**. It is a C++ Unreal Engine editor plugin that uses only
Unreal Engine modules and standard Unreal APIs (asset registry, asset renaming, DataAssets,
DataTables, editor UI). The bundled `Resources/` CSV and JSON files are plain settings data for the
plugin, not third-party software.

No external software, account, or runtime is required to install or use the plugin.

**Fab third-party software declaration:** no bundled third-party software.
