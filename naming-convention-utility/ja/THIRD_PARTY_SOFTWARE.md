# サードパーティ製ソフトウェア

Naming Convention Utility には、**サードパーティ製のソースコード、実行用バイナリ、AI モデル、Node.js、Python、独立した実行ファイルは一切含まれていません**。本プラグインは C++ で記述された Unreal Engine エディタプラグインであり、Unreal Engine の標準モジュールおよび API（アセットレジストリ、アセットリネームツール、DataAsset、DataTable、エディタ UI）のみを使用しています。`Resources/` フォルダ内の CSV および JSON ファイルは単なる設定データです。

プラグインのインストールおよび使用にあたり、外部ソフトウェア、アカウント、または追加の実行環境は不要です。

**Fab サードパーティ開示:** サードパーティ製ソフトウェアの同梱はありません。
