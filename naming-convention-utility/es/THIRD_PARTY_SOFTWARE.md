# Software de terceros

Naming Convention Utility **no incluye código fuente de terceros, binarios de ejecución, modelos de IA, Node.js, Python ni ejecutables independientes**. Es un plugin de editor para Unreal Engine escrito en C++ que utiliza exclusivamente los módulos de Unreal Engine y las API estándar (registro de assets, renombrado de assets, DataAssets, DataTables, interfaz del editor). Los archivos CSV y JSON de la carpeta `Resources/` son simples datos de configuración.

No se requiere ningún software externo, cuenta o entorno de ejecución para instalar o utilizar el plugin.

**Declaración Fab de terceros:** no se incluye software de terceros.
