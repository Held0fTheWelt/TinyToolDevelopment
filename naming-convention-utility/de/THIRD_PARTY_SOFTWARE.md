# Software von Drittanbietern

Naming Convention Utility **enthält keinen Quellcode von Drittanbietern, keine Runtime-Binärdateien, KI-Modelle, Node.js, Python oder eigenständige ausführbare Dateien**. Es handelt sich um ein C++ Unreal Engine Editor-Plugin, das ausschließlich Unreal Engine-Module und Standard-Unreal-APIs nutzt (Asset Registry, Asset-Umbenennung, DataAssets, DataTables, Editor-UI). Die mitgelieferten CSV- und JSON-Dateien im Ordner `Resources/` sind reine Einstellungsdaten für das Plugin und keine Software von Drittanbietern.

Es ist keine externe Software, kein Konto und keine zusätzliche Runtime erforderlich, um das Plugin zu installieren oder zu verwenden.

**Fab-Erklärung zu Software von Drittanbietern:** Keine mitgelieferte Software von Drittanbietern.
