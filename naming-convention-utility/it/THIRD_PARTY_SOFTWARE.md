# Software di terze parti

Naming Convention Utility **non include codice sorgente di terze parti, binari di esecuzione, modelli di IA, Node.js, Python o eseguibili indipendenti**. È un plugin per l'editor di Unreal Engine in C++ che utilizza esclusivamente i moduli di Unreal Engine e le API standard (registro degli asset, rinominazione degli asset, DataAsset, DataTable, interfaccia dell'editor). I file CSV e JSON nella cartella `Resources/` sono semplici dati di configurazione.

Nessun software esterno, account o ambiente di esecuzione è richiesto per installare o utilizzare il plugin.

**Dichiarazione Fab di terze parti:** nessun software di terze parti incluso.
