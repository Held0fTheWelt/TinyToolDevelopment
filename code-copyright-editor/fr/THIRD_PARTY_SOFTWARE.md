# Logiciels tiers

Code Copyright Editor **ne contient aucun code source tiers, binaire d'exécution, modèle IA, Node.js, Python ou exécutable autonome**. Il s'agit d'un plugin d'éditeur C++ pour Unreal Engine qui utilise uniquement les modules Unreal Engine et les API Unreal standard pour l'analyse de fichiers, les modèles, l'interface de l'éditeur et les rapports.

Aucun logiciel tiers, compte ou environnement d'exécution externe n'est requis pour installer ou utiliser le plugin.

**Déclaration de logiciels tiers Fab :** aucun logiciel tiers inclus.
