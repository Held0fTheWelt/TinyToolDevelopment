# Drittanbieter-Software

Code Copyright Editor **enthält keinen Quellcode von Drittanbietern, keine Laufzeit-Binärdateien, keine AI-Modelle, kein Node.js, Python oder eigenständige ausführbare Dateien**. Es ist ein C++ Unreal Engine Editor-Plugin, das ausschließlich Unreal Engine-Module und Standard-Unreal-APIs für Datei-Scanning, Vorlagenverarbeitung, Editor-UI und Berichte verwendet.

Für die Installation oder Nutzung des Plugins ist keine externe Software, kein Konto und keine externe Laufzeitumgebung erforderlich.

**Fab-Erklärung zu Drittanbieter-Software:** Keine enthaltene Drittanbieter-Software.
