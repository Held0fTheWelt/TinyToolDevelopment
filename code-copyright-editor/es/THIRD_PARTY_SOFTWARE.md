# Software de terceros

Code Copyright Editor **no incluye código fuente de terceros, binarios de tiempo de ejecución, modelos de IA, Node.js, Python ni ejecutables independientes**. Es un plugin de editor C++ para Unreal Engine que utiliza exclusivamente módulos de Unreal Engine y API estándar de Unreal para el escaneo de archivos, plantillas, interfaz del editor e informes.

No se requiere ningún software externo, cuenta ni entorno de ejecución externo para instalar o utilizar el plugin.

**Declaración de software de terceros Fab:** sin software de terceros incluido.
