# Software di terze parti

Code Copyright Editor **non include codice sorgente di terze parti, binari di runtime, modelli AI, Node.js, Python o eseguibili autonomi**. È un plugin per l'editor C++ di Unreal Engine che utilizza esclusivamente moduli di Unreal Engine e API Unreal standard per la scansione dei file, la gestione dei modelli, l'interfaccia utente dell'editor e i report.

Nessun software esterno, account o runtime esterno è richiesto per installare o utilizzare il plugin.

**Dichiarazione Fab sui software di terze parti:** nessun software di terze parti incluso.
