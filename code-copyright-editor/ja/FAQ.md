# FAQ (よくある質問)

## Code Copyright Editor は何に使用されますか？

Code Copyright Editor は、Unreal Engine 開発者が Project Settings およびソースファイル全体で一貫した著作権表示を管理するのを支援します。単一のエディターワークフローから、ソースファイルヘッダーのスキャン、プレビュー、更新、およびレポートが可能です。

## プラグインはランタイムのゲームプレイコードに影響しますか？

いいえ。Code Copyright Editor はエディター専用ツールです。開発、レビュー、ドキュメント作成、および CI ワークフローを目的としています。

## コードベース全体を自動的に更新できますか？

はい。ただしスキャンとレビューを行った後に限られます。エディターは、変更可能なファイル、保護されているファイル、および変更適用前に提案される置換内容を表示します。

## サードパーティや Epic の通知は保護されますか？

はい。スキャナーは、外部、Epic、およびサードパーティの通知が自動的に書き換えられないように保護する設計になっています。保護されたファイルおよびコンフリクトファイルは手動でレビューする必要があります。

## 著作権テンプレートをカスタマイズできますか？

はい。ソースファイル通知テンプレートと Project Settings 通知テンプレートを編集できます。製品名、ファイルパス、年、ライセンス識別子、ファイルごとの説明などのトークンを自動的に挿入できます。

## SPDX や REUSE ワークフローをサポートしていますか？

本プラグインは REUSE/SPDX 志向のテンプレートとレポートを提供します。これらのレポートはレビューおよび CI ワークフローをサポートすることを目的としていますが、法的認証を構成するものではありません。

## CI 用のコマンドレットはありますか？

はい。付属の `CodeCopyrightCheck` コマンドレットを使用してプロジェクトをスキャンし、オプションで変更可能なファイルを修正し、レポートを書き込み、著作権表示が同期していない場合に CI を失敗させることができます。

## 法的助言の代わりになりますか？

いいえ。通知テキストの一貫した適用とレビューを支援するものです。法的所有権の決定、サードパーティライセンスの検証、または法的助言を提供するものではありません。
