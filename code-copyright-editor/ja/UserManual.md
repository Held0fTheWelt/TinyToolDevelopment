# ユーザーマニュアル

このマニュアルでは、Code Copyright Editor の完全なエディターワークフローについて説明します。

## 目的

Code Copyright Editor は、次の2つの場所で著作権表示テキストを管理します：

- Unreal Engine プロジェクトレベルの著作権表示。
- 設定されたプロジェクトおよびプラグインフォルダ全体のソースファイルヘッダー。

本プラグインは、制御されたソース書き換え用に設計されています。まずスキャンし、プレビューを表示し、ユーザーがファイルを選択できるようにした上で、確認後に選択された変更可能ファイルのみを書き換えます。

## ツールを開く

プラグインを有効にした後、以下を開きます：

```text
Tools > Code Tools > Code Copyright Editor
```

プラグインの設定は以下からもアクセスできます：

```text
Project Settings > Plugins > Code Copyright Editor
```

## メインワークフロー

1. アイデンティティ、ライセンス、テンプレート、範囲、および保護設定を構成します。
2. 設定を保存します。
3. 必要に応じて Project Settings の通知を更新します。
4. コードベースをスキャンします。
5. ステータスバッジとプレビューを確認します。
6. オプションのファイルごとのメタデータを追加します。
7. 書き換えるべきファイルのみを選択します。
8. 選択したファイルを適用します。
9. 再度スキャンを実行して検証します。
10. レポートをエクスポートするか、CI でコマンドレットを実行します。

スキャンによってソースファイルが書き換えられることはありません。適用操作は、変更可能として分類されたチェック済みファイルのみを書き換えます。

## エディターのタブ

メインエディターウィンドウは、目的別のタブで構成されています：

| タブ | 目的 |
| --- | --- |
| `Configure` | テンプレート、所有者/ライセンス設定、スキャン範囲、保護ルール、およびプロジェクト通知設定を編集します。 |
| `Scan & Review` | スキャンを実行し、ファイルステータスを検査し、変更可能なファイルを選択し、ファイルを除外し、既存/提案通知を比較します。 |
| `File Metadata` | メタデータトークンによって表示される、選択したファイルの情報や説明を追加またはクリアします。 |
| `Apply & Reports` | 選択した書き換えを確認し、最新のエディター JSON スキャンレポートをエクスポートします。 |
| `Help` | 内蔵のワークフローガイドとステータス凡例を確認します。 |

## ステータス値

| ステータス | 意味 | 適用時の挙動 |
| --- | --- | --- |
| `OK` | ファイルはすでにレンダリングされたテンプレートと一致しています。 | 不要。 |
| `MISSING` | 互換性のある通知が見つかりませんでした。 | 有効な場合に挿入可能。 |
| `REPLACE` | 所有している通知または Unreal プレースホルダーを置き換え可能です。 | 書き換え可能。 |
| `PROTECTED` | 外部、Epic、またはサードパーティの通知が見つかりました。 | 自動的には書き換えられません。 |
| `CONFLICT` | 所有マーカーと保護マーカーの両方が検出されました。 | 手動レビューが必要です。 |
| `EXCLUDED` | ファイルが除外ルールに一致しました。 | 処理されません。 |
| `READ_ERROR` | ファイルを読み込めませんでした。 | 処理されません。 |
| `WRITE_ERROR` | ファイルを保存できませんでした。 | 処理されません。 |
| `UPDATED` | ファイルは前回の適用パスで書き込まれました。 | 再スキャンを実行して検証してください。 |

## ファイルごとのメタデータ

ファイルごとのメタデータは、グローバルテンプレートを変更することなく単一のファイルにコンテキストを追加します。

利用可能なメタデータ：

- `File Information`
- `Description`

推奨ワークフロー：

1. ファイルをスキャンします。
2. ファイルを選択します。
3. ファイル情報または説明を入力します。
4. `Save File Metadata` をクリックします。
5. テンプレートに `{FileMetadataBlock}` が含まれていることを確認します。
6. プレビューを確認します。
7. レンダリングされた通知が正しい場合は、ファイルを適用します。

`Clear File Metadata` は、選択したファイルの保存済みメタデータを削除します。

## 選択項目を適用 (Apply Selected)

適用する前に、エディターは確認を求めます。保護されたファイルおよびコンフリクトファイルは変更されません。

一括書き換えを行う前にソース管理を使用してください。初回パスでの安全性を高めるため、`Create Backup Before Write` を有効にすることをお勧めします。

## プラグインが行わないこと

Code Copyright Editor は以下の操作を行いません：

- 法的所有権の決定。
- ライセンス権限の付与。
- サードパーティライセンスの検証。
- 法的助言の代行。
- 保護された通知の自動書き換え。
- パッケージ化されたゲームでの実行。

本ツールは、通知、レポート、および CI チェックのための統合された技術的ワークフローを提供します。
