# サードパーティソフトウェア

Code Copyright Editor は、**サードパーティのソースコード、ランタイムバイナリ、AI モデル、Node.js、Python、または単体の実行可能ファイルを一切同梱していません**。ファイルスキャン、テンプレート処理、エディター UI、およびレポート作成には、Unreal Engine モジュールおよび標準の Unreal API のみを使用する C++ Unreal Engine エディタープラグインです。

プラグインのインストールや使用に、外部ソフトウェア、アカウント、または外部ランタイムは必要ありません。

**Fab サードパーティソフトウェア宣言:** 同梱サードパーティソフトウェアなし。
