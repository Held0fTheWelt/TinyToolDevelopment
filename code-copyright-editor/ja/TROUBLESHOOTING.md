# トラブルシューティング

このページでは、一般的な問題と実践的な解決策をまとめています。

## ツールが Tools メニューに表示されない

以下を確認してください：

- プラグインがプロジェクトで有効になっているか。
- プラグイン有効化後に Unreal Editor を再起動したか。
- 現在の Unreal Engine バージョン用にプラグインがビルドされているか。

予想されるメニューパス：

```text
Tools > Code Tools > Code Copyright Editor
```

## Project Settings ページが存在しない

以下を確認してください：

- プラグインモジュールが正常にロードされたか。
- パッケージ化されたランタイムビルドではなく、エディタービルドを使用しているか。
- プラグインがプロジェクトまたはエンジンのプラグインフォルダにインストールされているか。

## スキャンでファイルが見つからない

以下を確認してください：

- `ScanRootPaths` に存在するフォルダが含まれているか。
- ファイルがサポートされている拡張子を使用しているか。
- 除外パス断片が広すぎないか。

## ファイルが PROTECTED とマークされる

スキャナーが、所有マーカーと一致しない通知風のテキストを検出したか、または保護マーカーと一致しました。

解決策：

- サードパーティまたは Epic のコードである場合は、ファイルを変更せずに残します。
- ベンダーフォルダを除外に追加します。
- ファイルが本当にプロジェクトに属している場合のみ、所有マーカーを追加します。

## 書き込みエラー (Write Errors)

一般的な原因：

- ファイルが読み取り専用である。
- ファイルが別のプロセスによってロックされている。
- ソース管理でのチェックアウトが必要である。
- ユーザーアカウントに書き込み権限がない。

ファイルの状態を修正してから、再度スキャン/適用を実行してください。
