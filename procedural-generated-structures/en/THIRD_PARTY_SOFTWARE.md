# Third-Party Software

Procedural Generated Structures **bundles no third-party source code, runtime binaries, AI models,
Node.js, Python, or standalone executables**. It is a C++ Unreal Engine runtime plugin that uses
only Unreal Engine modules and standard Unreal APIs (instanced static mesh components, data assets,
actors).

No external software, account, or runtime is required to install or use the plugin. You supply your
own static meshes from your project content.

**Fab third-party software declaration:** no bundled third-party software.
