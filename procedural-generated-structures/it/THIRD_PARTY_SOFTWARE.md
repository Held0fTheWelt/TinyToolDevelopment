# Software di terze parti

Procedural Generated Structures **non include codice sorgente di terze parti, binari runtime, modelli di IA, Node.js, Python o eseguibili autonomi**. Si tratta di un plugin runtime C++ per Unreal Engine che utilizza esclusivamente moduli Unreal Engine e API standard di Unreal (componenti mesh statiche istanziate, asset di dati, actor).

Non è richiesto alcun software esterno, account o runtime per installare o utilizzare il plugin. L'utente fornisce le proprie mesh statiche dai contenuti del proprio progetto.

**Dichiarazione software di terze parti Fab:** nessun software di terze parti incluso.
