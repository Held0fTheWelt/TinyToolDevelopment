# サードパーティ製ソフトウェア

Procedural Generated Structures には、**サードパーティ製のソースコード、ランタイムバイナリ、AI モデル、Node.js、Python、スタンドアロン実行可能ファイルは一切バンドルされていません**。これは、Unreal Engine モジュールおよび標準の Unreal API（インスタンス化されたスタティックメッシュコンポーネント、データアセット、Actor）のみを使用する C++ Unreal Engine ランタイムプラグインです。

プラグインのインストールや使用に、外部ソフトウェア、アカウント、ランタイムは必要ありません。スタティックメッシュはプロジェクトコンテンツからご自身で用意してください。

**Fab サードパーティ製ソフトウェア宣言:** バンドルされたサードパーティ製ソフトウェアはありません。
