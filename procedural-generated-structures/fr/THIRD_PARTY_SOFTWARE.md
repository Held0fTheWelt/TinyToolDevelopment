# Logiciels tiers

Procedural Generated Structures **ne regroupe aucun code source tiers, binaire runtime, modèle IA, Node.js, Python ou exécutable indépendant**. Il s'agit d'un plugin C++ Unreal Engine runtime qui utilise uniquement les modules Unreal Engine et les API Unreal standard (composants de maillage statique instancié, assets de données, actors).

Aucun logiciel externe, compte ou runtime n'est requis pour installer ou utiliser le plugin. Vous fournissez vos propres maillages statiques à partir du contenu de votre projet.

**Déclaration de logiciels tiers Fab :** aucun logiciel tiers regroupé.
