# Software von Drittanbietern

Procedural Generated Structures **bündelt keinen Quellcode, keine Laufzeit-Binärdateien, keine AI-Modelle, kein Node.js, kein Python und keine eigenständigen ausführbaren Dateien von Drittanbietern**. Es ist ein C++ Unreal Engine Laufzeit-Plugin, das nur Unreal Engine Module und Standard-Unreal-APIs (instanziierte Static-Mesh-Komponenten, Data Assets, Actors) verwendet.

Es ist keine externe Software, kein Konto und keine externe Laufzeit erforderlich, um das Plugin zu installieren oder zu verwenden. Sie stellen Ihre eigenen Static Meshes aus Ihren Projektinhalten bereit.

**Fab-Erklärung zu Drittanbietersoftware:** Keine gebündelte Software von Drittanbietern.
