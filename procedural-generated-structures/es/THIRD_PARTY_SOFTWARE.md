# Software de terceros

Procedural Generated Structures **no incluye código fuente de terceros, binarios en tiempo de ejecución, modelos de IA, Node.js, Python ni ejecutables independientes**. Es un complemento en tiempo de ejecución C++ para Unreal Engine que utiliza únicamente módulos de Unreal Engine y API estándar de Unreal (componentes de malla estática instanciada, activos de datos, actores).

No se requiere ningún software externo, cuenta ni tiempo de ejecución para instalar o usar el complemento. Usted proporciona sus propias mallas estáticas a partir del contenido de su proyecto.

**Declaración de software de terceros de Fab:** ningún software de terceros incluido.
