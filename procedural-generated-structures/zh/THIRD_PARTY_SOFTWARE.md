# 第三方软件

Procedural Generated Structures **未捆绑任何第三方源代码、运行时二进制文件、AI 模型、Node.js、Python 或独立可执行文件**。它是一个 C++ Unreal Engine 运行时插件，仅使用 Unreal Engine 模块和标准 Unreal API（实例化静态网格体组件、数据资产、Actor）。

安装或使用本插件不需要外部软件、帐户或运行时。您从项目中自行提供静态网格体。

**Fab 第三方软件声明：** 无捆绑的第三方软件。
